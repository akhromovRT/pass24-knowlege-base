# create-pr — Автоматизация создания Pull Request

**Действие:** Запустить `pwsh -File scripts/create-pr.ps1` из корня репозитория. Скрипт делает push текущей ветки и создаёт PR (через `gh` или открывает браузер).

## Когда использовать

- После коммита изменений в feature-ветку
- Когда нужно отправить PR в main без ручных шагов

## Инструкции

### Шаг 1: Проверить состояние репозитория

Убедиться, что:
- Текущая ветка — не `main` (иначе PR не нужен)
- Изменения закоммичены (или пользователь согласен продолжить без коммита)

### Шаг 2: Запустить скрипт

**Из терминала (в корне репозитория):**
```powershell
powershell -ExecutionPolicy Bypass -File scripts/create-pr.ps1
```

**С параметрами (опционально):**
```powershell
powershell -ExecutionPolicy Bypass -File scripts/create-pr.ps1 -Title "Результаты цикла сделки" -Body "Данные из цикл1.xlsx"
```

### Шаг 3: Результат

- **Если установлен GitHub CLI (`gh`):** PR создаётся в терминале
- **Если нет:** Открывается браузер на странице `compare/main...<ветка>`, где пользователь нажимает "Create pull request"

## Примечания

- Скрипт автоматически делает `git push` текущей ветки
- Базовую ветку можно изменить: `-Base develop` (по умолчанию `main`)
- Установка GitHub CLI для полной автоматизации: `winget install GitHub.cli`

# Ежедневные отчёты (Маркетинг)

## Описание подраздела

Подраздел предназначен для ежедневных отчётов ведущего маркетолога: регламент заполнения и сами отчёты по дням.

## Документы

### [Регламент ежедневных отчётов](./Регламент%20ежедневных%20отчётов.md)

**Цели, задачи и формат ежедневного отчёта**

Содержит:
- Цели ежедневного отчёта (прозрачность, связность с базой знаний, учёт внешних данных, планирование)
- Задачи, которые описываются в отчёте (база знаний в Cursor, внешняя информация, метрики, действия, блокеры, планы на завтра)
- Два источника данных: изменения в базе знаний при работе в Cursor и внешняя информация, загруженная пользователем
- Короткий шаблон отчёта и пошаговую инструкцию заполнения
- Контрольный чек-лист и критерии успеха

**Используйте:** При заполнении ежедневного отчёта и при согласовании формата отчётности с руководством.

## Хранение отчётов по дням

Ежедневные отчёты сохраняются в этой папке в виде файлов с датой (например, `2026-02-09.md` или `09 февраля.md`) — по соглашению, принятому в отделе маркетинга.

## Связь с другими разделами

- Ежедневные отчёты служат входом для [еженедельной планерки по стратегии](../../01%20О%20компании/06%20Стратегия%202026/Еженедельная%20планерка/).
- Метрики из отчётов соотносятся с [результатами цикла сделки](../Цикл%20сделки/) и [HADI-гипотезами](../HADI-тесты/).

## Краткое описание

Комплексный анализ платформы Simplegate — конкурента PASS24.online в сегменте облачных систем контроля доступа. Документ содержит описание компании, продуктовой линейки (контроллеры, приложение, облачная платформа), тарифов, услуг, технической архитектуры и конкурентных преимуществ. Источник: simplegate.ru.

## Основной контент

### 1. Компания и её миссия

**Simplegate** — российская компания, разрабатывающая облачную систему контроля и управления доступом (СКУД). Позиционирует себя как производитель современного решения для автоматизации доступа на территорию жилых комплексов, бизнес-центров, коттеджных посёлков и других объектов.

**Миссия:** упростить управление доступом, сделать его удобным для жителей и управляющих компаний за счёт облачных технологий и мобильного приложения.

**Сайт:** [simplegate.ru](https://simplegate.ru)

**Ключевые тезисы позиционирования:**
- Облачная СКУД нового поколения
- Управление доступом через смартфон
- Интеграция с существующей инфраструктурой (шлагбаумы, ворота, домофоны, калитки)
- Отказ от физических носителей (карт, брелоков, пультов) в пользу мобильного приложения и BLE-технологий

### 4. Описание продуктов и решений

#### 4.1. Simplegate Cloud (облачная платформа)

Веб-панель управления для администраторов и управляющих компаний.

**Основные возможности:**
- Управление списками жителей и их правами доступа
- Настройка точек доступа (шлагбаумы, ворота, калитки, домофоны)
- Журнал событий с фильтрацией и поиском
- Управление гостевыми пропусками
- Отчёты по проезду и проходу
- Мультиобъектное управление (несколько ЖК в одном интерфейсе)
- Настройка расписаний доступа
- Управление ролями и правами администраторов

#### 4.2. Контроллеры Simplegate

Аппаратное оборудование — контроллеры, устанавливаемые на объекте и подключаемые к существующим исполнительным устройствам.

**Модельный ряд:**

| Модель | Назначение | Особенности |
|---|---|---|
| **Simplegate SG-1** | Универсальный контроллер для шлагбаумов и ворот | Поддержка BLE, Wi-Fi, Ethernet; 2 релейных выхода; «сухой контакт» |
| **Simplegate SG-2** | Контроллер для калиток и дверей | Компактный; 1 релейный выход; BLE + Wi-Fi |
| **Simplegate SG-D** | Контроллер для домофонов | Интеграция с подъездными домофонами; эмуляция ключа |

**Общие характеристики контроллеров:**
- Подключение к облаку через Wi-Fi или Ethernet
- Поддержка BLE (Bluetooth Low Energy) для связи с мобильным приложением
- Работа в автономном режиме при временной потере связи с облаком
- Обновление прошивки OTA (по воздуху)
- Питание: 12-24В DC
- Диапазон рабочих температур: от -40 до +60 C

#### 4.3. Мобильное приложение Simplegate

Приложение для жителей (iOS и Android).

**Функциональность:**
- Открытие шлагбаумов, ворот, калиток, домофонов одним нажатием
- BLE-идентификация (Bluetooth) — работает без интернета в радиусе действия контроллера
- Создание гостевых пропусков (ссылка или QR-код)
- Просмотр истории проездов/проходов
- Push-уведомления о событиях
- Управление несколькими объектами из одного приложения
- Автооткрытие (Hands-Free) — шлагбаум открывается при приближении автомобиля

#### 4.4. BLE-технология (Bluetooth Low Energy)

Ключевая технологическая особенность Simplegate — использование BLE для идентификации пользователя.

**Принцип работы:**
1. Смартфон жителя с установленным приложением приближается к контроллеру
2. Контроллер обнаруживает BLE-сигнал и идентифицирует пользователя
3. При наличии прав доступа — исполнительное устройство (шлагбаум/ворота) срабатывает

**Преимущества BLE:**
- Не требуется интернет-соединение на смартфоне в момент прохода
- Высокая скорость срабатывания (менее 1 секунды)
- Работает в фоновом режиме (не нужно открывать приложение)
- Безопасная криптографическая идентификация

**Ограничения:**
- Требуется включённый Bluetooth на смартфоне
- Дальность действия зависит от окружающей среды (обычно 5-15 метров)
- На старых устройствах может работать нестабильно

#### 4.5. Пульты и брелоки

Для жителей, не использующих смартфоны, Simplegate предлагает совместимость с радиопультами.

**Поддерживаемые варианты:**
- Встроенный приёмник 433 МГц в контроллере SG-1
- Поддержка стандартных пультов (совместимость с распространёнными моделями)
- Возможность привязки пультов через облачную панель

#### 4.6. Стойка вызова (Simplegate Intercom)

Устройство для установки на въезде, позволяющее посетителям без приложения позвонить жителю.

**Возможности:**
- Видеозвонок жителю через приложение
- Открытие доступа жителем дистанционно из приложения
- Устойчивость к погодным условиям (IP65)
- Интеграция с облачной платформой

<!-- Скриншот: стойка вызова Simplegate Intercom — внешний URL удалён, требуется локальная копия -->

#### 4.7. Гостевой доступ

Система предоставления временного доступа гостям и посетителям.

**Механизмы:**
- **Ссылка-приглашение:** житель создаёт ссылку, гость переходит по ней и получает временный BLE-ключ в приложении
- **QR-код:** гость показывает QR-код на стойке вызова или считывателе
- **Звонок через стойку:** гость нажимает кнопку вызова, житель открывает дистанционно
- **Код доступа:** одноразовый числовой код

**Настройки гостевого доступа:**
- Ограничение по времени действия (от 1 часа до нескольких дней)
- Ограничение по количеству проездов
- Выбор доступных точек (только шлагбаум, только калитка и т.д.)

### 7. Техническая архитектура системы

**Общая схема работы:**

```
Смартфон жителя (BLE/Internet)
        |
        v
Контроллер (SG-1/SG-2/SG-D)  <-->  Облако Simplegate Cloud
        |                                    |
        v                                    v
Исполнительное устройство          Веб-панель администратора
(шлагбаум, ворота, калитка)
```

**Компоненты архитектуры:**

1. **Облачная платформа** — серверная часть, размещённая в дата-центрах на территории РФ
2. **Контроллеры** — устройства на объекте, подключённые к облаку через Wi-Fi/Ethernet
3. **Мобильное приложение** — клиент для iOS/Android, связывается с облаком через интернет и с контроллером через BLE
4. **Веб-панель** — административный интерфейс для управления системой

**Протоколы и технологии:**
- BLE 4.2+ для локальной идентификации
- HTTPS/TLS для связи с облаком
- MQTT для обмена данными между контроллером и облаком (предположительно)
- REST API для интеграций (на тарифе Премиум)

**Автономный режим:**
- Контроллер хранит локальную копию списка доступа
- При потере связи с облаком продолжает работать по последней синхронизированной базе
- После восстановления связи — синхронизация событий с облаком

### 9. Конкурентные преимущества

**Сильные стороны Simplegate (по сравнению с рынком):**

| Преимущество | Описание |
|---|---|
| **BLE-идентификация** | Открытие без интернета, быстрая и удобная авторизация через Bluetooth |
| **Hands-Free режим** | Автоматическое открытие при приближении — не нужно доставать телефон |
| **Облачное управление** | Нет необходимости в локальных серверах, доступ из любой точки |
| **Совместимость** | Работает с существующими шлагбаумами и воротами (CAME, NICE, DoorHan и др.) |
| **Модульность** | Можно начать с одного контроллера и масштабировать постепенно |
| **Гостевой доступ** | Гибкие механизмы предоставления временного доступа (ссылки, QR, коды) |
| **Мультиобъектность** | Управление несколькими объектами из одной панели |
| **Российское производство** | Оборудование и ПО разработаны в России |

**Потенциальные слабые стороны:**
- Зависимость от облака (хотя есть автономный режим)
- Необходимость стабильного интернет-соединения на объекте для полноценной работы
- Непрозрачное ценообразование (цены по запросу)
- Относительно узкий модельный ряд контроллеров
- Нет собственного решения для распознавания номеров автомобилей (в отличие от PASS24)
- Ограниченная интеграция с домофонными системами (только определённые модели)

## Часть 1. Анализ pass24market.ru

### 1.1 Что такое PASS24.market

**PASS24.market** — электронный каталог услуг, встроенный в экосистему PASS24.online, предоставляемых арендаторам и собственникам жилья. Платформа работает по модели **B2B2C**:

```
Сервисная компания → Управляющая компания/PASS24 → Жильцы/Резиденты
```

Продукт решает три задачи одновременно:
- **Для управляющей компании:** новый источник монетизации без инвестиций в инфраструктуру
- **Для жильцов:** единое место заказа услуг внутри уже знакомого приложения
- **Для сервисной компании:** готовый канал сбыта к платёжеспособной и территориально концентрированной аудитории

#### УТП (Уникальные торговые предложения) платформы

1. **Только % за результат** — управляющая компания и сервисная компания платят только за оформленные заявки, без абонентской платы за размещение
2. **Готовая аудитория** — жильцы уже используют приложение PASS24, дополнительной конверсии «скачать приложение» не нужно
3. **Брендирование** — маркетплейс брендируется под логотип управляющей компании
4. **Эквайринг на стороне платформы** — PASS24.market берёт на себя обработку платежей
5. **Аналитика** — сервисная компания видит динамику заказов, оплат и предпочтений
6. **Кураторский подход** — не открытый каталог, а отобранные партнёры

**Ключевые характеристики аудитории:**
- Территориально сконцентрированы (поселок, ЖК, БЦ)

- Высокая цифровая грамотность (уже используют мобильное приложение)
- Реальная потребность в бытовых, ремонтных и сервисных услугах

## Часть 6. Рекомендации по доработке сайта pass24market.ru

### 6.1 Выявленные пробелы

1. **Нет публичного лендинга для сервисных компаний** — страница про подключение к маркетплейсу в качестве поставщика услуг отсутствует или не индексируется
2. **Семантика не охватывает B2B-запросы** — нет контента под запросы: «как разместить услуги в приложении для жильцов», «стать партнёром ЖК-маркетплейса», «канал сбыта для клинингового бизнеса»
3. **Отсутствует социальное доказательство** — кейсов сервисных компаний-партнёров нет в открытом доступе
4. **CTA для партнёров не выражен** — нет формы «стать поставщиком услуг»

### 6.2 Рекомендации

| Приоритет | Действие | Результат |
|-----------|----------|-----------|
| 🔴 Срочно | Создать посадочную страницу «Для сервисных компаний» | Инструмент для входящих обращений |
| 🔴 Срочно | Добавить форму «Хочу разместить услуги» на главную | Захват лидов |
| 🟡 Важно | Опубликовать 2–3 кейса партнёров с цифрами | Социальное доказательство |
| 🟡 Важно | SEO-контент под B2B-запросы (клининг, ремонт для ЖК/КП) | Органический трафик |
| 🟢 Желательно | FAQ для сервисных компаний (как работает комиссия, как подключиться) | Снижение барьера входа |

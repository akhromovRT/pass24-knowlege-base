# Цикл сделки

## Описание раздела

Раздел содержит отчёты и аналитику по циклу сделки PASS24 — метрики воронки продаж, длительность этапов (лид → демо → закрытие) и результаты по продуктам (Облако, Оборудование).

## Структура документов

### 📊 [Результаты за 4 квартал 2025](./Результаты%20за%204%20квартал%202025.md)

**Сводные данные по циклу сделки за 4 квартал 2025 года**

Содержит:
- Количество лидов, демонстраций и закрытых сделок по продуктам
- Сделки в работе на дату отчётности (31.01.2026)
- Среднюю длительность цикла в днях (продукт, оборудование, всего)
- Методологию расчёта и правила учёта

**Используйте:** При анализе эффективности продаж, подготовке отчётов, работе с HADI-циклами и гипотезами ускорения сделок.

**Каталог из 25 гипотез для ускорения цикла сделки PASS24**

Содержит:
- Сводную таблицу гипотез
- Описания и вариации реализации для каждой гипотезы
- Ссылки на методологию HADI и полный реестр с метриками

**Используйте:** При выборе гипотез для тестирования, планировании HADI-циклов, подготовке пилотов.

### 📘 [План для 1 гипотезы](./План%20для%201%20гипотезы.md)

**Champion Kit для пилота H01: 1 КПП + 1 сценарий (14 дней)**

## Связь с другими разделами

- **HADI-тесты** — данные о цикле сделки используются для планирования и оценки экспериментов по его сокращению
- **Отдел продаж (ОП)** — метрики воронки напрямую связаны с процессами ОП

### 2. pass24market.ru — Блокеры P0

> 🔴 До устранения P0 — рекламный трафик нецелесообразен. 5 блокеров P0 и 4 проблемы P1.

| Приоритет | Блокер | Последствие |
|-----------|--------|------------|
| **P0** | Нет каталога услуг (все внутренние страницы → 404) | Клиент не понимает, что купить |
| **P0** | Счётчики показывают «0» на главной | Полное разрушение доверия при первом визите |
| **P0** | Нет реальных партнёров / услуг | Нечего показать клиенту |
| **P0** | Форма «Оставить заявку» — статус неизвестен | Лиды могут теряться незаметно |
| **P0** | Нет аналитики | Деньги на рекламу без измерения |
| P1 | 404-страница на английском | Плохой UX |
| P1 | Нет контактной информации | Снижение доверия |
| P1 | Форма «Стать партнёром» не верифицирована | Потеря партнёрских лидов |
| P1 | Мобильная версия не проверена | Возможный обрыв воронки |

### 4. onvis.ru — Smoke-test

**🔴 Критические проблемы:**

- **CTA-ссылка с прошедшей датой** — URL содержит `?date=2026-03-05`, дата прошла. Клиент нажимает «Записаться» → видит просроченный слот → уходит. **Исправить немедленно**
- **/pricing → 404** — нет страницы тарифов. Клиент не может узнать стоимость
- **Нет формы на сайте** — единственный способ связи: внешняя ссылка Plannerka. При недоступности сервиса — 100% потеря лидов

**🟡 Проблемы P1:**
- /about → 404, /contact → 404
- Нет телефона и email на сайте
- Лиды из Plannerka → CRM: неизвестно, передаётся ли UTM
- Нет тарифов и условий работы

**✅ Что работает хорошо:**
- Сильная главная: боли → решение → процесс → цифры → CTA
- Чёткое позиционирование: «AI-отдел продаж за 14 дней»
- Живая визуализация AI-агентов с реальными статусами
- Убедительные метрики результатов (+83%, x3, −40%, +50%)

### 6. Мониторинг после изменений

**Ежедневно первые 3 дня после правок:**
- 0 лидов при активном трафике → немедленная проверка форм и CRM
- Plannerka недоступна → резервная форма работает
- Рост 404-ошибок → проверка всех ссылок

**Еженедельно:**
- Количество заявок по каждому источнику в CRM
- Bounce rate с рекламного трафика
- Бронирования в Plannerka (onvis.ru) — конверсия в звонки

## Контрольный чек-лист

**pass24market.ru после правок:**
- [ ] Тестовая заявка через «Оставить заявку» → CRM → уведомление → ответ

# PASS24 Market — Парсер сервисных компаний

Бот собирает базу сервисных компаний Москвы и МО для маркетплейса **pass24market.ru**.

---

## Версии парсера

| Файл | Источники | Статус |
|------|-----------|--------|
| `parser_v3.py` | DuckDuckGo + requests + BS4 | **Актуальный** (бесплатно, без API-ключей) |
| `parser_v2.py` | DuckDuckGo + requests + BS4 | Предыдущая версия |
| `parser_bot.py` | Firecrawl API | Устарел (платный API) |

---

---

## Что делает бот (v3)

1. Ищет сайты компаний через **DuckDuckGo** по 12 категориям (без API-ключей)
2. Скрапит каждый сайт: название, телефон, email, сайт, ВКонтакте, Telegram, **WhatsApp**, адрес
3. Автоматически проверяет страницу контактов, если телефон не найден на главной
4. **Дедуплицирует** по домену, телефону и названию
5. Расставляет **приоритеты P1 / P2 / P3** по критериям из методологии
6. Сохраняет **checkpoint** каждые 10 сайтов — можно прервать и продолжить
7. Сохраняет результаты в папку `data/`

## Установка и запуск (v3)

### Шаг 1: Установить зависимости

```powershell
pip install requests beautifulsoup4 pandas openpyxl duckduckgo-search
```

> API-ключи не нужны — всё бесплатно.

### Шаг 2: Запустить парсер

```powershell
# Полный прогон по всем 12 категориям
py parser_v3.py

# Быстрый режим (меньше URL, для теста)
py parser_v3.py --fast

# Только одна категория
py parser_v3.py --category "Клининг"

# Продолжить прерванный парсинг
py parser_v3.py --resume

# Только поиск без скрапинга сайтов (очень быстро)
py parser_v3.py --no-scrape
```

## Результаты

После запуска в папке `data/` появятся файлы:

| Файл | Описание |
|------|----------|
| `companies_YYYY-MM-DD.xlsx` | Основной файл с листами: Все, P1, P2, P3, по категориям |
| `companies_YYYY-MM-DD.csv` | CSV-версия для Google Таблиц |
| `companies_raw_YYYY-MM-DD.json` | Сырые данные от Firecrawl |

### Структура Excel

| Поле | Описание |
|------|----------|
| priority | P1 / P2 / P3 |
| category | Категория услуги |
| company_name | Название компании |
| phone | Телефон |
| email | Email |
| website | Сайт |
| vk_url | ВКонтакте |
| telegram | Telegram |
| rating | Рейтинг |
| reviews_count | Количество отзывов |
| address | Адрес / зона работы |
| works_in_suburbs | Работает в загородке |
| source | Источник (Zoon / Profi / Search) |
| status | Статус обработки (заполняет менеджер) |
| contact_date | Дата обращения |
| manager_comment | Комментарий |

## Критерии приоритетов

**P1 (высокий приоритет)** — сумма баллов ≥ 7:
- Упоминает загород / МО / коттедж в описании (+3)
- Рейтинг ≥ 4.5 (+2)
- Отзывов ≥ 15 (+2)
- Есть сайт (+1)
- Есть email (+1)
- Есть соцсети (+1)

**P2** — 4–6 баллов  
**P3** — 0–3 балла

## Зачем это нужно

### Контекст

PASS24.online — система управления доступом для коттеджных посёлков. Сейчас к платформе подключено **500+ посёлков**, ею пользуются **50 000+ жителей** Москвы и МО ежедневно. Это сформировавшаяся, платёжеспособная, верифицированная аудитория.

pass24market.ru — маркетплейс услуг, встроенный в экосистему PASS24. Жители видят его внутри приложения, которым пользуются каждый день для пропускного режима. Это означает:
- **Нулевая стоимость привлечения трафика** для сервисных компаний на старте
- **Тёплая аудитория** — жители уже доверяют бренду PASS24 (он охраняет их дом)
- **Геотаргетинг** — показ только в нужных посёлках, в радиусе работы партнёра

### Проблема, которую решает процесс

Маркетплейс без партнёров — пустая витрина. Чтобы он стал ценным для жителей и начал генерировать выручку, необходимо наполнить его проверенными сервисными компаниями по 15+ категориям услуг, актуальных для загородной жизни.

| Цель | Показатель | Срок |

## Процесс шаг за шагом

### Этап 1 — Сбор базы (парсинг)

**Кто:** Ассистент / маркетолог
**Срок:** 4–5 недель

1. Подготовить Google Таблицу с полями: название, телефон, email, сайт, источник, рейтинг, приоритет, статус, комментарий
2. Собрать компании по 14 категориям из источников:
   - 2ГИС — основной источник (есть API)
   - Яндекс Карты / Яндекс Бизнес
   - Авито Услуги (ручной сбор)
   - SEO-поиск Яндекс / Google (ТОП-20 по запросам)
   - Profi.ru, Zoon.ru, YouDo.com
   - ВКонтакте и Telegram (активные бизнес-аккаунты)
   - HeadHunter (компании, нанимающие под загородный сегмент)
3. Расставить приоритеты: **P1** (клининг, сад, сантехника, электрика) → **P2** → **P3**
4. Провести дедупликацию
5. Передать в работу менеджеру порциями по 20–30 компаний в день

**Плановый объём:** ~450 компаний

---

### Этап 2 — Первичный контакт

**Кто:** Менеджер по партнёрствам
**Инструменты:** Email, WhatsApp, Telegram, холодный звонок

1. Выбрать подходящий шаблон КП под категорию компании
2. Персонализировать: вписать название компании, сезонный аргумент, геозону
3. Отправить через наиболее доступный канал (email / мессенджер / звонок)
4. Зафиксировать в CRM: дата, канал, статус «Отправлено КП»

**Ключевое предложение при первом контакте:**
- Бесплатное размещение на 2 месяца
- Прямые заявки без посредников
- Геотаргетинг только по нужным посёлкам

---

### Этап 3 — Цепочка касаний (follow-up)

**Кто:** Менеджер по партнёрствам

| День | Действие |
|------|----------|
| День 1 | Первое письмо / сообщение / звонок |
| День 4 | Напоминание в мессенджер |
| День 10 | Повторное письмо с дополнительным аргументом (сезон / конкуренты уже зашли) |
| День 21 | Финальное сообщение — закрытие темы |

---

### Этап 4 — Переговоры и подключение

**Кто:** Менеджер по партнёрствам + Технический отдел

1. При положительном ответе — уточнить категорию, геозону, желаемый канал приёма заявок
2. Передать данные в техотдел для создания карточки на pass24market.ru
3. Согласовать с партнёром контент карточки (описание, фото, контакты)
4. Активировать карточку, запустить показы
5. Зафиксировать в CRM статус «Партнёр»

---

### Этап 5 — Конверсия в платное размещение

**Кто:** Менеджер по партнёрствам

- Через 6–8 недель после активации — связаться с партнёром, получить обратную связь по качеству заявок
- Предложить переход на платную подписку
- Модель монетизации — по типу компании (Freemium → Подписка / CPL / Комиссия)

## Что это даёт каждой стороне

### Сервисной компании
- Доступ к 50 000+ загородных жителей без рекламного бюджета
- Геотаргетинг: только свой радиус работы
- Прямые заявки (звонок / WhatsApp / форма)
- Значок «Проверено PASS24» — встроенное доверие аудитории
- Бесплатный старт 2 месяца

### PASS24 / pass24market.ru
- Наполнение маркетплейса релевантными партнёрами
- Новая точка монетизации платформы (выручка с размещений)
- Повышение ценности приложения для жителей
- Дополнительный аргумент для продаж посёлкам («у нас маркетплейс услуг»)

### Жителям посёлков
- Проверенные сервисы рядом с домом, внутри привычного приложения
- Не нужно искать в чатах или Яндексе — всё собрано в одном месте
- Компании верифицированы платформой

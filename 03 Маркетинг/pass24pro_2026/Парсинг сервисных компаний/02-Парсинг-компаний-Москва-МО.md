## Краткое описание

Методология поиска и сбора контактов сервисных компаний Москвы и МО, работающих в сегменте загородной недвижимости и коттеджных посёлков. Описаны основные источники данных, поисковые запросы по категориям, формат хранения базы и приоритизация компаний.

## Источники данных

### Источник 1: 2ГИС (moscow.2gis.ru)

**Что даёт:** Наиболее полная база организаций с телефонами, адресами, сайтами. Есть API для автоматизации.

**Запросы для поиска:**

| Категория | Запрос в 2ГИС |
|-----------|--------------|
| Клининг | `уборка коттеджей москва`, `клининг загородных домов`, `уборка дач` |
| Уход за садом | `уход за садом москва область`, `ландшафтный дизайн коттеджный посёлок`, `стрижка газона выезд` |
| Сантехника | `сантехник выезд подмосковье`, `сантехник загородный дом` |
| Электрика | `электрик подмосковье выезд`, `электромонтаж загородный дом` |
| Вывоз мусора | `вывоз строительного мусора подмосковье`, `вывоз КГМ московская область` |
| Дрова | `доставка дров московская область`, `дрова с доставкой подмосковье` |
| Бассейны | `обслуживание бассейнов москва`, `чистка бассейна выезд` |

**Как парсить:**
1. Открыть 2ГИС, ввести запрос, фильтр: Москва + МО
2. Выгрузить список компаний вручную или через 2ГИС API (ключ — в разделе developer.2gis.ru)
3. Сохранить: название, телефон, сайт, адрес, рейтинг

**Инструменты автоматизации:**
- [2GIS API](https://docs.2gis.com/ru/api/search/get-started) — поиск организаций по запросу + координатам
- Альтернативно: Google Таблицы + ImportXML (ручной экспорт) для небольших объёмов

---

### Источник 2: Яндекс Карты / Яндекс Бизнес

**Что даёт:** Контакты, сайты, отзывы. Хорошо покрывает малый бизнес МО.

**Запросы:**

```
клининг дачи москва
уход за садом подмосковье
сантехник загородный дом
электрик выезд МО
вывоз мусора коттеджный посёлок
```

**Как парсить:**
- Яндекс Карты: поиск → список компаний → ручной сбор или через Яндекс Геосервисы API
- Яндекс Бизнес: профили компаний содержат телефон, email, мессенджеры

---

### Источник 3: Авито Услуги (avito.ru/moskva_i_mo/predlozheniya_uslug)

**Что даёт:** Частные мастера и небольшие компании, которых нет в 2ГИС. Прямые контакты.

**Запросы для поиска на Авито:**

```
уборка дома выезд подмосковье
уход за садом коттедж
сантехник загород
электрик частный дом
вывоз мусора дача
стрижка газона
```

**Важно:** Авито запрещает автопарсинг. Сбор вручную или через браузерные расширения типа Avito Parser (проверить актуальность).

---

### Источник 4: Яндекс Поиск + Google

**Что даёт:** Компании, которые тратят деньги на SEO или рекламу — значит, активно ищут клиентов. Мотивированные партнёры.

**Поисковые запросы:**

```
клининг коттеджей Москва (МО / подмосковье)
уборка загородного дома цена
садовник для коттеджного посёлка
вызов сантехника Московская область
выездная химчистка диванов коттедж
```

**Как собирать:**
- ТОП-20 сайтов по каждому запросу
- Зайти на сайт → найти контактную форму / email / телефон
- Хранить: URL, название, контакт, категория

---

### Источник 5: Каталоги и агрегаторы услуг

**Zoon.ru, Profi.ru, YouDo.com, Remontnik.ru:**

| Платформа | Что искать | Как использовать |
|-----------|-----------|-----------------|
| Profi.ru | Компании (не физики), рейтинг >4.5, отзывов >20 | Выгрузить список, взять email/телефон из профиля |
| Zoon.ru | Карточки компаний с контактами | Поиск по категории + МО |
| YouDo.com | Организации с высоким рейтингом | Категории "уборка", "сантехника", "сад" |

---

### Источник 6: ВКонтакте и Telegram

**Что даёт:** Активные бизнесы с аудиторией, готовые к партнёрствам. Часто более гибкие к переговорам.

**Как искать ВКонтакте:**
- Поиск сообществ: "клининг подмосковье", "уборка дач мо", "садовник коттедж"
- Фильтр: подписчики 500-10000, последние посты <30 дней
- Взять контакт из раздела "Контакты" / "Связаться"

**Как искать Telegram:**
- Поиск: @gardenmsk, @cleaningmo, "уход за садом москва"
- Каналы с регулярными постами услуг
- Связь: написать напрямую в личку или на admin@

---

### Источник 7: HeadHunter (hh.ru)

**Нестандартный источник.** Компании, нанимающие сотрудников для загородного сегмента, явно активны.

**Запросы:**
```
уборщица коттеджный посёлок
садовник загородный дом
мастер на все руки МО
```
**Как использовать:** Найти компанию-работодателя → зайти на сайт → взять контакт.

## Приоритизация компаний

### Признаки высокоприоритетного партнёра (P1)

- Рейтинг на агрегаторах ≥ 4.5 и ≥ 15 отзывов
- Явно указывает загородный сегмент в описании услуг
- Есть сайт (не только Авито/агрегатор)
- Активна в соцсетях (посты за последние 30 дней)
- Не более 2–3 городов охвата (значит, локально сфокусирована)

### Признаки низкого приоритета

- Только физическое лицо без ИП/ООО
- Последняя активность >3 месяцев назад
- Работает только в Москве, не МО
- Уже является клиентом крупного агрегатора (Profi, YouDo — может конфликтовать)

## Пошаговая инструкция сбора базы

### Шаг 1: Подготовка таблицы

**Что делать:**
1. Создать Google Таблицу по структуре из раздела "Формат базы данных"
2. Создать отдельный лист для каждой приоритетной категории
3. Настроить выпадающий список для поля "Статус"

**Результат:** Готовая таблица для заполнения

---

### Шаг 2: Сбор по источникам (P1-категории)

**Что делать:**
1. Начать с 2ГИС — наибольший охват, структурированные данные
2. Для каждой категории из P1 — прогнать 3–5 запросов
3. Занести компании в таблицу: название, телефон, сайт, источник
4. Дополнить из Яндекс Карт и Avito

**Дневная норма:** 30–50 компаний в день (ручной сбор)

---

### Шаг 3: Верификация и приоритизация

**Что делать:**
1. Зайти на сайт / профиль каждой компании
2. Проверить признаки высокого приоритета (рейтинг, активность, загородный сегмент)
3. Поставить приоритет P1/P2/P3 в таблице
4. Компании без сайта и без признаков активности — удалить или пометить P3

---

### Шаг 4: Дедупликация

**Что делать:**
1. Проверить на дубли (одна компания в нескольких источниках)
2. Оставить одну строку, выбрав наиболее полные контакты
3. В поле "Источник" указать все источники через запятую

---

### Шаг 5: Передача в работу

**Что делать:**
1. Отсортировать по приоритету: P1 → P2 → P3
2. Назначить ответственного менеджера
3. Передать в работу порциями по 20–30 компаний в день

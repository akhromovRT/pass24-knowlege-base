> ⚠️ Требует утверждения руководством

### Варианты модели

| Вариант | Описание | Плюсы | Минусы |
|---------|----------|-------|--------|
| **A — Прямая лицензия** | Продаём лицензию PASS24 напрямую через Marketplace | Простота, понятная цена | Требует готовности Marketplace к приёму оплаты |
| **B — Лид → консультация → продажа** | Marketplace собирает лиды, продажа идёт через менеджера | Гибкость, высокий чек | Длиннее цикл сделки |
| **C — Freemium / Trial** | Бесплатный период → конверсия в платную подписку | Низкий барьер входа | Требует воронки активации |
| **D — Эксперимент: A/B лендинги** | Тест двух офферов (лицензия vs консультация) | Данные для решения | Сложнее в управлении |

## Шаг 5. Аналитика под тест

### Обязательные события для настройки

| Событие | Триггер | Тип |
|---------|---------|-----|
| `page_view` | Любая страница Marketplace | Auto |
| `form_view` | Пользователь увидел форму | Custom |
| `form_submit` | Нажал «Отправить» | Custom — цель конверсии |
| `thank_you_page` | Открылась страница /thank-you | Custom — цель конверсии |
| `cta_click` | Клик по основной CTA-кнопке | Custom |
| `lead_to_crm` | Лид создан в Bitrix | Server-side (Bitrix Webhook) |

### Настройка целей

- [ ] Цель «Отправка формы» в Яндекс Метрике
- [ ] Цель «Thank You Page» (дублирующая цель)
- [ ] CTA click event
- [ ] Связь с Bitrix: лид из рекламы помечается UTM-меткой в карточке

### Тест цепочки

```
Тест: клик по объявлению → посадочная с UTM → заполнение формы
→ страница /thank-you → создание лида в Bitrix с UTM
→ событие в аналитике → отчёт
```

- [ ] Тест пройден вручную перед запуском
- [ ] UTM корректно прописывается в карточку лида в Bitrix
- [ ] Отчёт «Источники лидов» показывает данные

## Шаг 6. Pre-launch чеклист

### Технический

- [ ] Посадочная страница открывается без ошибок
- [ ] Форма отправляет лид в Bitrix
- [ ] После отправки — редирект на /thank-you
- [ ] Событие `form_submit` фиксируется в Метрике / GA
- [ ] UTM-метки прокидываются в CRM
- [ ] Мобильная версия страницы работает корректно
- [ ] Скорость страницы: Google PageSpeed ≥60 (mobile)
- [ ] 404 на посадочной отсутствуют

### Рекламный

- [ ] Объявления прошли модерацию
- [ ] Бюджет установлен с дневным лимитом
- [ ] Стоп-правила прописаны в настройках кампании
- [ ] UTM-метки во всех объявлениях
- [ ] Аудитория подобрана корректно

### Организационный

- [ ] Менеджер знает, что идут лиды (и откуда)
- [ ] SLA на обработку лида установлен: ≤ [X] часов
- [ ] Отчёт «daily performance» договорились смотреть в [время]

### Правило оптимизации

| Ситуация | Действие |
|----------|----------|

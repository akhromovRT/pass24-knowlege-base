## Краткое описание

Данный документ содержит структурированное обучение по веб-интерфейсу PASS24.online на основе записи встречи от 14.10.2025 для объекта Поликлиника (номер объекта 2173). В документе рассмотрены все основные модули системы: сотрудники, права, пользователи, адреса, пропуска, объекты (настройки, КПП, чёрный список, типы транспорта), доверенности, рассылка, отчёты. Также описаны процессы авторизации, массовой загрузки, блокировок, работа с запросами, экспорт отчётов и упоминание интеграции с камерами. Особенность обучения — детальный пример настройки подгруппы охраны с пошаговым разбором прав по каждому модулю.

### Модуль Сотрудники

**Назначение:** Сотрудники — это администраторы системы, которые имеют доступ на редактирование, добавление, создание пропусков, удаление пользователей, добавление пользователей и другие административные действия в веб-интерфейсе.

**Права главного администратора:**
- Абсолютно все права на редактирование и изменение системы
- Может добавлять помощников (других администраторов)

#### Штатные сотрудники системы

**Важно:** При создании системы автоматически добавляются несколько штатных сотрудников, в том числе учётная запись технической поддержки PASS24. **Не трогайте и не удаляйте** эти учётные записи.

#### Добавление нового сотрудника

**Что делать:**

1. Нажмите **«Новый сотрудник»**
2. Заполните данные:
   - **Имя** (обязательно) — можно просто имя или ФИО полностью
   - **Почта** (обязательно) — желательно действующая, так как является логином для авторизации и используется для сброса пароля
   - **Пароль** (обязательно) — можно придумать абсолютно любой
   - **Номер телефона** (необязательно)
3. Выберите **группу** (по стандарту — «Администраторы»; если создана подгруппа «Охрана», можно выбрать её)
4. Обязательно поставьте **галочку напротив названия вашего объекта** — этим вы присваиваете сотрудника к объекту
5. Нажмите **«Сохранить»**

**Где:** Раздел «Сотрудники», кнопка «Новый сотрудник»

**Результат:** Сотрудник добавлен и имеет доступ к системе

**Важно:**
- Если почта будет выдуманная, могут быть проблемы с восстановлением пароля
- При создании сотрудника можно выбрать КПП (подробнее в разделе «Объекты»)

#### Редактирование прав сотрудника

**Что делать:**

1. Напротив необходимого сотрудника нажмите **три точки**
2. Выберите **«Редактировать права»**
3. Откроются настройки каждого отдельного модуля (слева)
4. Выставьте необходимые ограничения (например, запретить доступ к разделу «Пользователи»)
5. Обязательно нажмите **«Сохранить»**

**Где:** Раздел «Сотрудники», три точки → «Редактировать права»

**Результат:** Человек, авторизованный под эту учётную запись, не будет видеть запрещённые разделы

**Пример с пропусками:** Можно дать возможность создания пропусков, но выбрать по пунктам — например, только разовые и временные, а постоянные пропуска оставить только для главных администраторов.

#### Удаление и редактирование сотрудника

**Что делать:**

- **Удалить:** три точки → «Удалить»
- **Редактировать данные:** три точки → «Редактировать» (изменить имя, пароль, почту и т.д.)

### Модуль Права

**Назначение:** Создание групп прав для разделения сотрудников по уровням доступа.

#### Создание подгруппы (на примере охраны)

**Что делать:**

1. В разделе «Права» по стандарту есть одна основная группа — **«Все администраторы»**
2. Нажмите **«Создать подгруппу»** внутри группы «Все администраторы»
3. Назовите подгруппу (например, **«Охрана»**)
4. Нажмите **«Сохранить»**
5. **Подождите 10-15 секунд** — процесс небыстрый, так как применяются все права и настройки

**Где:** Раздел «Права»

**Результат:** Подгруппа создана, появляется в выборе при создании сотрудника

**Важно:** **Не нажимайте кнопку «Сохранить» несколько раз!** Каждое нажатие отправляет команду на создание. Если нажать 10 раз — создастся 10 одинаковых подгрупп, и потом придётся всё чистить.

#### Перемещение сотрудника в подгруппу

**Что делать:**

1. Просто **перетащите** сотрудника из группы «Все администраторы» в подгруппу «Охрана»

**Результат:** Сотрудник теперь находится в группе охраны и имеет те настройки, которые вы выставите для этой подгруппы.

#### Настройка прав подгруппы охраны (детальный пример)

**Что делать:**

1. Нажмите **«Настроить права»** у подгруппы «Охрана»
2. Пройдитесь по каждому модулю:

| Модуль | Рекомендуемая настройка для охраны |
|--------|-----------------------------------|
| **Сотрудники** | Запрещён |
| **Права** | Запрещён |
| **Пользователи** | Разрешён (просмотр), редактирование/создание/удаление — запрещено |
| **Адреса** | Разрешён (просмотр), редактирование/создание/удаление — запрещено |
| **Пропуска** | Доступ разрешён, создание — разрешено (но без выбора типов), редактирование — **только статус**, удаление — запрещено, экспорт — запрещено, закрытие — разрешено |

3. Нажмите **«Сохранить»**

**Где:** Раздел «Права», подгруппа «Охрана», кнопка «Настроить права»

**Результат:** Все настройки применяются ко всем сотрудникам в этой подгруппе

**Важно:**
- Рекомендуется оставлять охранникам просмотр адресов и пользователей, чтобы они видели, на кого пропуск создан и по какому адресу
- Редактирование пропусков — **только статус**, чтобы охранник мог нажимать «Приехал»/«Уехал»
- **Закрытие** рекомендуется оставить — при необходимости охранники смогут закрывать просроченные пропуска
- **Наследование от родительской группы** — подгруппа наследует права от группы, к которой относится

#### Создание вложенных подгрупп

**Что делать:**

- Если нужна ещё одна подгруппа, можно создать её **внутри подгруппы охраны** — тогда новая подгруппа автоматически перенимает уже настроенные права
- Если нужны админские права — создавайте подгруппу от группы «Все администраторы»

**Для удаления** подгруппы нажмите на **корзиночку** рядом с группой.

### Модуль Пользователи

**Назначение:** Пользователи — это пользователи мобильного приложения. У них более ограниченный функционал: по факту они могут только создавать пропуска. Никаких прав по редактированию системы, добавлению адресов, пользователей у них нет.

**Важно:** Сотрудники и пользователи — это **две разные сущности**. Сотрудники работают в веб-интерфейсе, пользователи — в мобильном приложении.

#### Добавление пользователя вручную

**Что делать:**

1. Нажмите **«Добавить»**
2. Заполните данные:
   - **Имя или ФИО** (обязательно — либо имя, либо отчество должно быть заполнено)
   - **Номер телефона** (обязательно — идентификатор для входа в мобильное приложение)
   - Адрес (если уже создан)
   - Группа пользователей (необязательно)
3. Нажмите **«Сохранить»**

**Где:** Раздел «Пользователи», кнопка «Добавить»

**Результат:** Пользователь добавлен в систему

#### Самостоятельная регистрация пользователя

**Что делать (со стороны пользователя):**

1. Пользователь скачивает мобильное приложение
2. Начинает процесс регистрации
3. Приложение запрашивает **номер объекта** — уникальный идентификатор системы
4. Пользователь вводит номер (например, **2173**)
5. Создаётся запрос на присоединение к объекту

**Где посмотреть номер объекта:** Раздел «Объекты» → выберите ваш объект → уникальный идентификатор отображается в карточке

**Обработка запроса (со стороны администратора):**

1. Запрос появляется в разделе **«Запросы»**
2. Одобрите запрос — только после этого пользователь появится в системе

**Важно:** Если пользователь не знает номер объекта, он не сможет подключиться.

#### Массовая загрузка пользователей с адресами

**Что делать:**

1. Перейдите в раздел **«Адреса»**
2. Нажмите на **облачко со стрелочкой** (Импорт)
3. Выберите **«Пример с пользователями»** → **«Скачать»**
4. Откроется Excel-табличка — заполните в идентичном формате адреса и данные пользователей
5. Выберите ваш объект, нажмите **«Выбрать»**
6. Перетащите заполненную Excel-табличку

**Где:** Раздел «Адреса», кнопка «Импорт»

**Результат:** Добавятся сразу и пользователи, и адреса, и пользователи присвоятся к тем адресам, напротив которых вы их записали

#### Блокировка пользователя

**Что делать:**

1. Найдите пользователя в списке
2. Перетащите **ползунок** на блокировку
3. Оставьте **комментарий** (внутренний, пользователь его не увидит)
4. Нажмите **«Подтвердить»**

**Что даёт блокировка:**

- При попытке создания пропуска пользователю выйдет ошибка: **«Вы заблокированы, обратитесь к администраторам системы»**
- Пропуска, созданные до блокировки, **остаются активными** — их можно закрыть отдельно или оставить

**Снятие блокировки:** ползунок перетаскиваем в неактивное состояние → «Сохранить»

#### Поиск и настройка отображения

**Поисковая строка:** можно искать по номеру телефона или по ФИО

**Настройка полей (шестерёнка):**

1. Нажмите **шестерёнку**
2. Поставьте галочки напротив необходимых полей: адреса, комментарии блокировки, статус «Зарегистрирован»
3. Сохраните

**Статус «Зарегистрирован»:** Если вы внесли пользователя в систему, но он ещё ни разу не авторизовался — будет «Нет». После первой авторизации — «Да». Позволяет отслеживать, кто действительно пользуется мобильным приложением.

**Дополнительные фильтры:** по регистрации, блокировке, блокировке адресов, блокировке на адресе.

### Модуль Адреса

**Назначение:** Управление адресами объекта.

#### Добавление адресов

**Варианты:**

- **Импорт** (облачко со стрелочкой): пример с пользователями или без — скачайте образец, заполните, загрузите
- **Вручную** (кнопка «Добавить»): внесите все необходимые данные

#### Короткое название адреса

**Назначение:** Внутренняя пометка (например, «Отделение», «Корпус 2»). На ваше усмотрение.

#### Блокировка адреса

**Полная блокировка адреса:**

- Активируйте блокировку адреса — **все пользователи** на этом адресе не смогут создать пропуск

**Блокировка отдельного пользователя на адресе:**

- В редактировании адреса нажмите **«Заблокировать пользователя на адресе»** — только этот пользователь заблокирован, остальные на адресе могут создавать пропуска

**Снятие:** идентичным путём — переключить ползунок обратно.

#### Поиск и настройка отображения

**Поисковая строка:** по улице, дому или адресу. Через шестерёнку можно настроить отображаемые поля (идентично разделу «Пользователи»).

### Модуль Пропуска

**Назначение:** Основной модуль системы. Здесь отображаются все пропуска, созданные в системе.

**Видимое ограничение:** в списке отображаются **60 последних пропусков**, соответствующих установленным фильтрам. Если нужного пропуска нет в списке — используйте поисковую строку.

#### Создание пропуска

**Что делать:**

1. Нажмите **«Новый пропуск»**
2. Выберите **адрес** (если на адресе один пользователь — выбирается автоматически, иначе раскройте и выберите)
3. Выберите **тип пропуска**:
   - **Разовый** — закрывается после одного цикла (приехал → уехал)
   - **Временный** — действует определённый период (неделя, месяц и т.д.), можно многократно менять статус
   - **Постоянный** — действует бессрочно, до ручного закрытия
4. Выберите **дату начала и окончания** (кроме постоянного)
5. Выберите **автомобиль** или **пешеход**
6. Для автомобиля заполните:
   - **Тип автомобиля** (грузовой, легковой, доставка, такси — внутренняя пометка)
   - **Марка** (можно писать на русском, идёт автоматический поиск: «МРС» → Mercedes-Benz)
   - **Номер автомобиля** по стандартам ГРЗ
7. Нажмите **«Сохранить»**

**Где:** Раздел «Пропуска», кнопка «Новый пропуск»

**Результат:** Пропуск создан

#### Добавление нескольких гостей

**Что делать:**

1. При создании пропуска нажмите **«Добавить гостя»**
2. Заполните данные следующего гостя
3. Повторите для каждого дополнительного гостя
4. При нажатии **«Сохранить»** все пропуска создадутся одновременно

#### Типы пропусков: логика работы

**Разовый пропуск:**
- Нажимаете **«Приехал»** → статус «На территории»
- Нажимаете **«Уехал»** → статус «Вне территории» → пропуск **автоматически закрывается**

**Постоянный пропуск:**
- Можно бесконечно делать события «Приехал»/«Уехал»
- Закрывается только **вручную** (статус должен быть «Вне территории», затем кнопка «Закрыть»)

**Временный пропуск:**
- Действует в указанный период
- Можно многократно менять статус
- По истечении срока — действие зависит от настроек объекта
- Можно закрыть раньше времени вручную

#### Дата начала действия пропуска

**Важно:** Срок действия пропуска начинается **с момента указанной даты начала**, а НЕ с момента приезда гостя. Например, если создан пропуск на 24 часа с 14 октября 12:38 — отсчёт начинается с 12:38, вне зависимости от того, приехал гость или нет.

**В мобильном приложении** есть шаблонные варианты: 6 часов, 12 часов, 24 часа.

**Можно создать пропуск наперёд** — например, сегодня вторник, а гость приедет в пятницу. Указываете дату начала на пятницу.

#### Фильтрация пропусков

**Фильтры по типу (галочки вверху):**
- Разовые, временные, постоянные
- На территории, вне территории, просроченные, закрытые

**Практический пример:** Чтобы видеть только постоянные пропуска (например, автомобили сотрудников) — уберите галочки «Разовые» и «Временные», оставьте только «Постоянные».

**Поисковая строка:** по ФИО (для пешеходов) или по номеру авто. Учтите: при вводе 777 система найдёт и совпадения по номеру, и по региону.

**Дополнительные фильтры:** период активности, пользователь, адрес, объект (для мультиобъектов), тип (автомобильный/пешеходный).

#### Смена статуса пропуска

**Что делать:**

1. Найдите пропуск в списке или через поиск
2. Раскройте карточку пропуска
3. Нажмите **«Приехал»** — статус меняется на «На территории»
4. Нажмите **«Уехал»** — статус меняется на «Вне территории»

**Все события фиксируются:** с какой учётной записи была произведена смена статуса.

#### Редактирование пропуска

**Условия:**

- Пропуск можно редактировать **только до первого события** (до нажатия «Приехал»)
- Можно изменить: пользователя, марку, номерной знак
- После первой смены статуса — редактирование **полностью закрывается**

**Причина:** Сделано в целях безопасности, чтобы не было фальсификации данных. Если произошло ЧП и нужно поднять историю — данные не могут быть подменены.

#### Закрытие пропусков

**Постоянный/временный пропуск:**

1. Обязательно смените статус на **«Вне территории»**
2. Только после этого появится кнопка **«Закрыть»**
3. Если статус «На территории» — кнопки закрытия не будет

#### Массовое закрытие пропусков

**Что делать:**

1. Отфильтруйте нужные пропуска (по пользователю, типу, и т.д.)
2. Поставьте **галочки** напротив нужных пропусков или **«Выбрать все найденные»**
3. Нажмите появившуюся кнопку **«Закрыть выбранные»**

**Где:** Раздел «Пропуска»

**Результат:** Все выбранные пропуска закрываются

#### Экспорт событий пропусков

**Что делать:**

1. В разделе «Пропуска» нажмите **«Экспортировать события пропусков»**
2. Выберите **период** (максимум **31 день**)
3. При необходимости выберите пользователя и адрес (если не заполнять — считаются все)
4. Нажмите **«Отправить»**

**Результат:** Отчёт в формате Excel приходит на email учётной записи. В отчёте: номер автомобиля/ФИО пешехода, тип пропуска, кем создан, все события (дата, время, кто нажал).

**Важно:**
- Максимум за **31 день** — период можно выставлять как угодно (не обязательно с 1 по 31)
- Для более глубоких данных — запрос в техническую поддержку (данные хранятся с самого начала функционирования системы)
- Ничего не удаляется, только закрывается и улетает в более глубокий архив

### Модуль Запросы

**Назначение:** Обработка запросов от пользователей мобильного приложения.

**Типы запросов:**

- **Запрос на доверенность**
- **Запрос на пропуск** (если настроен режим «По запросу»)
- **Запрос на присоединение** (самостоятельная регистрация пользователя)
- **Сообщение в УК** (переписка между пользователем и администратором, рассчитано на поселки/ЖК)

**Обработка:**

1. Запрос появляется в разделе «Запросы»
2. Нажмите на запрос
3. Выберите **«Одобрить»** или **«Отклонить»**

**Фильтрация:** по статусу запроса, сортировка (сначала новые/неотработанные), поисковая строка по типу, ФИО, номеру телефона.

### Модуль Доверенности

**Назначение:** Временный доступ в систему со стандартным функционалом пользователя на определённый период.

**Пример использования:** Собственник имеет три участка, живёт в одном, два сдаёт в аренду. Вместо создания отдельного пользователя оформляется доверенность на определённый срок (год, полгода).

**Что происходит по истечении срока:**

- Пользователь-доверенное лицо **автоматически удаляется** из системы
- Все его активные пропуска **закрываются**

**Примечание:** Для объекта Поликлиника модуль доверенностей, скорее всего, не актуален.

### Модуль Объекты: настройки

**Где:** Выберите ваш объект → откроются все настройки

#### Лимиты пропусков

**Важно:** Лимит действует **на весь объект**, не на конкретного пользователя или адрес.

**Пример:** Если поставить лимит разовых автомобильных пропусков в 50 — при 50 активных разовых пропусках 51-й не создастся (ошибка «Превышен лимит активных пропусков»).

#### Создание пропусков для сотрудников

**Опции:**

| Настройка | Описание |
|-----------|----------|
| **Разрешить** | Пропуск сразу попадает в активные |
| **Запретить** | Сотрудник не может создавать данный тип пропуска |
| **По запросу** | Пропуск уходит в запросы, требуется одобрение главного админа |

**Применение:** Главный администратор может сделать так, чтобы все сотрудники создавали постоянные пропуска только по запросу.

#### Настройки для пользователей мобильного приложения

**Разовые и временные пропуска:**

- **Разрешить** — пропуск сразу попадает в действующие (автоматический режим)
- **По запросу** — попадает в раздел «Запросы», требуется одобрение

**Важно:**
- Разовые пропуска запретить нельзя — это базовый функционал
- Временные можно запретить — при попытке создания у пользователя поле будет неактивным
- **Постоянные пропуска всегда попадают в запросы** — автоматического режима для них нет

#### Марка автомобиля и формат номера

- **Марка автомобиля обязательна** — ползунок: если неактивен, марку можно не указывать
- **Формат номера обязателен** — ползунок: если неактивен, можно создать пропуск с номером «723 АМ» без региона
- **Белорусские номера:** при создании нельзя указывать тире и точки, вводите номер слитно

#### Автоматическое действие при истечении срока пропуска

**Условие:** Срок пропуска истёк, но статус — «На территории».

**Варианты:**

| Вариант | Описание | Рекомендация |
|---------|----------|-------------|
| **Просроченный** | Подсвечивается красным, не закрывается | Не рекомендуется — копятся тысячи пропусков, система тормозит |
| **Продлевать на 1 час** | Продлевается до смены статуса | Актуально при автораспознавании номеров |
| **Закрыть** | Принудительное закрытие | **Рекомендуется** — избегает накопления просроченных |

#### Максимальный срок действия пропусков

- **Разовый пропуск** — устанавливается в часах (рекомендуется 24 часа)
- **Временный пропуск** — устанавливается в часах (неделя = 168 часов, месяц ≈ 720 часов)
- **Постоянный** — бесконечный, настройки нет

**Обязательно** нажимайте **«Применить»** после каждого изменения в подразделах настроек.

#### Работа с запросами (настройки)

- Можно отключить **запрос на создание постоянного пропуска** — тогда пользователи мобильного приложения не смогут создавать постоянные пропуска вообще
- Остальные настройки запросов также регулируются здесь

#### Номер телефона объекта

Пользователи мобильного приложения видят этот номер в разделе «Объекты». Рекомендуется указать номер сотрудника, который может проконсультировать по вопросам работы PASS24.

#### КПП

**Назначение:** Разделение списков пропусков между сотрудниками на разных въездах.

**Пример:** Два въезда — север и юг. Создаёте два КПП, присваиваете адреса, каждому охраннику назначаете свой КПП. Каждый видит только пропуска своего КПП.

**Что делать:**

1. Перейдите в раздел «КПП» в карточке объекта
2. Создайте КПП, укажите название
3. Добавьте адреса к КПП
4. При создании/редактировании сотрудника выберите нужный КПП

**Применение:** Для разделения информации и отчётности между разными точками входа.

#### Чёрный список

**Назначение:** Список автомобильных номеров, которым запрещён въезд.

**Что делать:**

1. Перейдите в раздел **«Чёрный список»**
2. Нажмите **«Добавить»**
3. Введите автомобильный номер
4. Сохраните

**Результат:** При попытке создать пропуск на этот номер — восклицательный знак «Номер находится в чёрном списке». Даже если сотрудник проигнорирует предупреждение и нажмёт «Сохранить» — будет ошибка, пропуск не создастся.

#### Типы транспорта

**Назначение:** Разделение пропусков по типу транспорта (грузовые, легковые, транзитные и т.д.).

**Что делать:**

1. Нажмите **«Добавить»**
2. Введите описание типа транспорта
3. Укажите **сортировку в списках** — порядок отображения при выборе (1, 2, 3...)

### Модуль Рассылка

**Назначение:** Массовая рассылка push-уведомлений пользователям мобильного приложения.

**Что делать:**

1. Выберите **тип рассылки**:
   - Пользователям по адресам
   - Конкретным пользователям
   - Всем пользователям по объекту
2. Выберите **объект**
3. Введите **заголовок** и **текст рассылки**
4. Нажмите **«Сохранить»**

**Результат:** Всем пользователям приходит push-уведомление. Если текст не умещается — пользователь нажимает на уведомление, попадает в ленту событий мобильного приложения и читает полный текст.

**Применение:** Плановые работы, экстренные отключения, важные объявления.

### Модуль Отчёты

**Назначение:** Выгрузка статистики и данных для анализа.

#### Типы отчётов

**1. Отчёт по пропускам**

- Период: до **3 месяцев**
- Содержит: все пропуска, созданные в указанный период (кем, когда, какого типа)
- Фильтры: по типу пропуска, статусу, типу гостя (если ничего не выбрано — считаются все)
- Применение: отследить, сколько пропусков создал конкретный сотрудник за месяц

**2. Отчёт по событиям пропусков**

- Аналогичен экспорту событий из раздела «Пропуска» (31 день)

**3. Отчёт по пользователям**

- Выгружает **актуальный список** пользователей (без указания периода)
- Применение: проверить, не забыли ли кого-то внести или удалить

**4. Отчёт по адресам**

- Какие адреса были созданы в указанный период

**Результат:** Отчёт приходит на email учётной записи в формате Excel.

### Интеграция с камерами

**Упоминание в обучении:** У PASS24 есть более продвинутые тарифы с системой автораспознавания номеров.

**Как работает:**

- Специальные камеры определяют номер автомобиля
- Сверяются с пропусками в системе
- Автоматически открывают/закрывают шлагбаум
- События фиксируются от сотрудника **«Интеграция»** в истории пропусков

**Для установки:** PASS24 выезжает на аудит, оценивает специфику въезда, ставит камеру под нужный угол.

**Примечание:** На стандартном тарифе функция недоступна. Вопрос рассматривается на будущее.

### Авторизация пользователей

**Три способа добавления пользователя в систему:**

1. **Вручную** — через раздел «Пользователи», кнопка «Добавить»
2. **Самостоятельная регистрация** — через мобильное приложение с указанием номера объекта
3. **Массовая загрузка** — через импорт Excel-таблички в разделе «Адреса»

**Первичная авторизация:**

1. Пользователь заходит в мобильное приложение
2. Нажимает **«Забыли пароль»** (пароль ещё не задан)
3. Вводит номер телефона → получает SMS-код
4. Задаёт себе новый пароль → авторизуется

**Авторизация сотрудников:**

- Используется **email** для входа в веб-интерфейс
- Если пароль забыт — на почту приходит письмо для сброса (поэтому почта должна быть действующей)

## Часто задаваемые вопросы (FAQ)

### Вопрос 1: Что означает «КПП отсутствует» при создании сотрудника?

**Ответ:** Это нормально, если вы ещё не создали КПП в разделе «Объекты». КПП нужны для разделения списков пропусков между разными точками входа. Если у вас один въезд — КПП можно не создавать.

---

### Вопрос 2: Можно ли видеть список только постоянных пропусков (например, автомобили сотрудников)?

**Ответ:** Да. В разделе «Пропуска» уберите галочки с «Разовые» и «Временные», оставьте только «Постоянные». Отобразится полный перечень только постоянных пропусков.

---

### Вопрос 3: Сколько по умолчанию действует пропуск?

**Ответ:** Зависит от настроек объекта. В разделе «Объекты» → «Настройки» можно установить максимальный срок действия разового (рекомендуется 24 часа) и временного пропуска (в часах). В мобильном приложении есть шаблоны: 6/12/24 часа.

---

### Вопрос 4: Когда начинается отсчёт срока действия пропуска?

**Ответ:** С момента указанной даты начала действия, а не с момента приезда гостя. Если создан пропуск на 24 часа с 14 октября 12:38 — срок начинается с 12:38, вне зависимости от того, приехал гость или нет.

---

### Вопрос 5: Где охрана видит пропуска в веб-интерфейсе?

**Ответ:** В разделе **«Пропуска»**. Охрана работает только через веб-интерфейс, не через мобильное приложение. Пользователи мобильного приложения видят только свои пропуска.

---

### Вопрос 6: Можно ли редактировать пропуск после приезда гостя?

**Ответ:** Нет. Редактирование закрывается после первой смены статуса. Это сделано в целях безопасности — чтобы нельзя было подменить данные задним числом.

---

### Вопрос 7: Что делать, если нужны данные за период более 31 дня?

**Ответ:** Обратитесь в техническую поддержку PASS24. Все данные хранятся в архиве с момента создания системы и могут быть выгружены по запросу.

---

### Вопрос 8: Можно ли создавать пропуска наперёд?

**Ответ:** Да. При создании пропуска укажите дату начала действия в будущем. Например, сегодня вторник, а гость приедет в пятницу — создаёте пропуск с датой начала на пятницу.

---

### Вопрос 9: Как работает автораспознавание номеров?

**Ответ:** Доступно на расширенных тарифах. Специальные камеры определяют номер автомобиля, сверяются с пропусками в системе, автоматически открывают/закрывают шлагбаум. PASS24 выезжает на аудит и устанавливает оборудование.

---

### Вопрос 10: Где взять номер объекта для самостоятельной регистрации пользователей?

**Ответ:** В разделе «Объекты» → выберите ваш объект → уникальный идентификатор отображается в карточке (например, 2173).

## Типичные ошибки и их решение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Создалось 10 одинаковых подгрупп | Нажали «Сохранить» несколько раз при создании подгруппы | Удалить лишние, впредь нажимать один раз и ждать 10-15 секунд |
| Номер находится в чёрном списке | Автомобиль добавлен в чёрный список объекта | Удалить номер из чёрного списка в настройках объекта |
| Нельзя редактировать пропуск | Пропуск уже сменил статус (нажали «Приехал») | Редактирование невозможно после первого события — в целях безопасности |
| Система подтормаживает | Много просроченных пропусков | В настройках объекта установить «Закрыть» вместо «Перевести в просроченные» |
| Пользователь не может присоединиться | Неправильный номер объекта или запрос не одобрен | Проверить номер в разделе «Объекты», одобрить запрос в разделе «Запросы» |
| При вводе номера 777 находятся чужие пропуска | Совпадение с регионом | Ввести полный номер для точного поиска |
| Почта выдуманная — невозможно восстановить пароль | При создании сотрудника указана несуществующая почта | Редактировать сотрудника: три точки → «Редактировать» → сменить почту на действующую |

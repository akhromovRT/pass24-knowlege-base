## Краткое описание

Данный документ содержит структурированное обучение по веб-интерфейсу PASS24.online на основе записи встречи от 22.10.2025 для объекта «Сходня инжиниринг» (номер объекта 2121, адрес Некрасова 2). В документе рассмотрены все основные модули системы. Особенность обучения — акцент на специфике бизнес-парка: арендаторы с постоянными пропусками, процедура полной блокировки арендатора-должника, ограничения ручного открытия шлагбаума, разделение событий по КПП при едином адресе и отслеживание ночной парковки через отчёты.

### Модуль Сотрудники

**Назначение:** Сотрудники — это администраторы системы, которые могут настраивать систему, добавлять и удалять пользователей, редактировать адреса. По сути — хозяева системы.

#### Создание сотрудника

**Что делать:**
1. Нажмите **«Новый сотрудник»**
2. Заполните данные: ФИО, email, пароль
3. Обязательно укажите **реально существующий email** — он используется для авторизации и восстановления пароля

**Где:** Раздел «Сотрудники», кнопка «Новый сотрудник»

**Результат:** Сотрудник добавлен; при первом входе авторизуется по email и паролю

**Важно:** Если email выдуманный — при утере пароля восстановить доступ будет невозможно.

#### Редактирование прав и назначение КПП

**Что делать:**
1. Нажмите **три точки** напротив сотрудника
2. Выберите **«Редактировать права»** — откроется список модулей
3. Для охранника: ограничьте доступ только модулем «Пропуска»
4. В разделе редактирования сотрудника выберите **«Выберите КПП»** — укажите КПП, к которому прикреплён охранник
5. Поставьте галочку напротив объекта

**Где:** Раздел «Сотрудники», три точки → «Редактировать» / «Редактировать права»

**Результат:** Охранник видит только свой КПП и только модуль пропусков

**Практика:** На объекте Сходня инжиниринг создана группа «Охрана» с правами только на просмотр и смену статуса пропусков. Отдельные учётные записи для КПП-1 и КПП-2.

### Модуль Права

**Назначение:** Создание групп прав для разграничения доступа сотрудников.

**Основные действия:**
- **Создание группы:** кнопка «Создать группу», назвать (например, «Охрана», «Администраторы»)
- **Настройка прав:** нажмите шестерёнку у группы → проходите по модулям, задавая уровень доступа: **наследовать**, **разрешён**, **запрещён**
- **Присвоение сотруднику:** при создании/редактировании сотрудника выберите группу из списка

**Рекомендуемые права для охраны:**
- Сотрудники — запрещён
- Права — запрещён
- Пользователи — только просмотр
- Пропуска — просмотр + смена статуса
- Все остальные модули — запрещён

**Где:** Раздел «Права»

### Модуль Пользователи

**Назначение:** Управление арендаторами, сотрудниками объекта и другими людьми, которые создают пропуска через мобильное приложение.

**Важное разграничение:**
- **Сотрудники** (в разделе «Сотрудники») — это администраторы, управляющие системой
- **Пользователи** (в этом разделе) — это арендаторы, жители и любые люди, которые получают пропуска

#### Группы пользователей

На объекте могут быть группы: «Арендаторы», «Сотрудники», «Хостел» и другие. Группы создаются вручную через кнопку **«Создать группу»**.

**Как правильно внести сотрудников объекта (50-100 человек):**
1. Создайте группу «Сотрудники» (объектные, не системные)
2. Добавьте каждого человека как пользователя с привязкой к этой группе
3. Создайте на каждого **постоянный пропуск**

**Важно:** Не объединяйте всех сотрудников под одним фиктивным арендатором — это приводит к путанице в отчётах и статистике.

#### Добавление пользователя вручную

**Что делать:**
1. Нажмите **«Добавить»**
2. Заполните: ФИО, номер телефона (формат +7), при необходимости email
3. Выберите **группу** (арендаторы, сотрудники и т.д.)
4. Присвойте **адрес**
5. Нажмите **«Сохранить»**

**Где:** Раздел «Пользователи», кнопка «Добавить»

#### Массовая загрузка пользователей через Excel

**Что делать:**
1. Нажмите **«Импорт»**
2. Выберите **«Пример с пользователями»** → скачайте шаблон
3. Заполните: в одной строке — адрес, далее ФИО и номер телефона пользователей
4. Выберите объект, загрузите файл

**Ограничение:** При массовой загрузке **нельзя назначить группу** — пользователи окажутся без группы. Если нужно разделение по группам, добавляйте вручную.

#### Настройки отображения (шестерёнка)

Через иконку шестерёнки можно включить отображение дополнительных столбцов: группа, адрес, статус регистрации и другие. Фильтрация по группе позволяет быстро найти нужных пользователей.

#### Блокировка пользователя

**Что делает блокировка:** Запрещает пользователю создавать новые пропуска. **Не закрывает** уже созданные и активные пропуска.

**Что делать:**
1. Найдите пользователя
2. Откройте **«Редактировать»**
3. Переключите ползунок **«Блокировка»** в активное состояние
4. Оставьте внутренний комментарий (пользователь его не увидит)
5. Нажмите **«Подтвердить»**

**Результат:** Пользователь при попытке создать пропуск увидит сообщение: «Вы заблокированы, обратитесь к администраторам системы».

**Важно:** Для полной блокировки арендатора (въезд + создание) см. раздел «Полная блокировка арендатора-должника».

### Модуль Адреса

**Назначение:** Управление адресами объекта. У Сходня инжиниринг один адрес — Некрасова 2.

#### Блокировка адреса

**Что делает:** При блокировке одного адреса **все пользователи, привязанные к нему, теряют возможность создавать пропуска** на этот адрес. По сути — блокировка всех пользователей разом.

**Где:** Раздел «Адреса», замочек у адреса

**Применение:** Актуально в крайних ситуациях (например, форс-мажор, когда нужно временно закрыть весь въезд).

### Модуль Пропуска

**Назначение:** Управление пропусками всех типов на территорию.

#### Типы пропусков

| Тип | Когда закрывается |
|---|---|
| **Разовый** | После одного полного цикла: въезд → выезд. Или по истечении срока действия. |
| **Временный** | По истечении заданного срока действия (неограниченное количество въездов в этот период) |
| **Постоянный** | Только вручную |

**Практический пример:**
- Арендатор на своём Mercedes — **постоянный пропуск**
- Газель с доставкой для арендатора — **временный** (на день-два) или **разовый**

#### Полная блокировка арендатора-должника

**Задача:** Закрыть все пропуска арендатора (постоянные, временные, разовые) и запретить создание новых.

**Что делать:**
1. Перейдите в раздел **«Пропуска»**
2. Убедитесь, что в фильтрах включены **все типы**: постоянные, временные, разовые (галочки должны стоять)
3. В фильтрах выберите **пользователя** (должника)
4. Нажмите **«Режим массового закрытия»**
5. Нажмите **«Выбрать все найденные»**
6. Нажмите **«Закрыть»**
7. Перейдите в раздел **«Пользователи»**, найдите арендатора
8. Заблокируйте пользователя (ползунок + комментарий)

**Где:** Раздел «Пропуска», кнопка «Режим массового закрытия»

**Результат:** Все пропуска закрыты, новые создавать невозможно. При въезде автоматика не откроет шлагбаум.

**Важно:** Порядок шагов (сначала закрыть пропуска или сначала заблокировать пользователя) практически не важен — разница в несколько секунд, и арендатор не успеет создать новые пропуска.

#### Поведение просроченного пропуска при нахождении на территории

**Ситуация:** Временный пропуск истёк, но автомобиль ещё на территории (статус «На территории»).

**Правило:** Пропуск со статусом «На территории» **не может быть закрыт**. Камера его не отработает на выезд. Нужно сначала сменить статус на «Вне территории».

**Три варианта в настройках объекта:**

1. **Перевести в просроченные** — пропуск остаётся в списке, видимый, до ручного закрытия. Не рекомендуется при большом потоке: накапливаются тысячи незакрытых пропусков → система тормозит.
2. **Продлевать на час** — пропуск автоматически продлевается на 1 час; после того как автомобиль уедет и сменится статус, закроется. Актуально для платных въездов.
3. **Принудительно закрыть** — пропуск закрывается немедленно по истечении времени, даже если автомобиль на территории. Охрана должна вручную сменить статус на «Вне территории» и выпустить. Рекомендуется для большинства объектов.

#### Экспорт событий пропусков

**Что делать:**
1. Нажмите **«Экспортировать события пропусков»** (иконка облака со стрелкой)
2. Выберите **период** (максимум 31 день)
3. При необходимости выберите **пользователя** или оставьте пустым (все)
4. Нажмите **«Отправить»**

**Результат:** Отчёт в Excel приходит на почту учётной записи. Содержит: пользователь, номер автомобиля, время въезда/выезда, инициатор события (сотрудник охраны, интеграция, администратор).

**Важно:** За данными старше 31 дня — в техподдержку. Данные хранятся в архиве и предоставляются по запросу.

#### Ручная смена статуса охраной

Охранник может вручную нажать «Приехал» / «Уехал» в разделе пропусков — это событие **фиксируется в системе** с именем учётной записи охранника, датой и временем. Это решение проблемы с грязными номерами: охранник видит пропуск, нажимает «Приехал» вручную.

### Модуль Объекты: настройки

**Где:** Раздел «Объекты» → выбрать объект

#### Номер телефона объекта

Номер, который видят пользователи мобильного приложения. Рекомендуется указать контактный телефон ответственного за PASS24 (горячая линия для арендаторов).

#### Настройки создания пропусков

Для каждого типа пропусков можно настроить режим:
- **Разрешить** — пропуск сразу попадает в активные
- **По запросу** — уходит в раздел «Запросы», требует подтверждения администратора
- **Запретить** (только для временных) — пользователи/сотрудники не могут создавать этот тип

**Важно:** Пользователи мобильного приложения могут создавать постоянный пропуск **только через запрос** (этот режим нельзя изменить на «Разрешить» для постоянных со стороны пользователей). Для сотрудников — можно настроить «Разрешить».

#### Лимиты пропусков

Лимит действует **на всю систему**, а не на конкретного пользователя или адрес. Например, лимит 50 разовых означает, что в системе не может быть больше 50 одновременно активных разовых пропусков.

**Квотирование по пользователю:** На момент обучения (октябрь 2025) квотирование работает только по адресу. Возможность квотирования по пользователю — в проработке у отдела разработки.

#### Автоматическое действие при истечении срока пропуска

Настраивается в карточке объекта. Три варианта: просроченный, продлевать на час, принудительно закрыть. Подробнее — в разделе «Поведение просроченного пропуска».

#### Максимальный срок действия пропусков

- **Разовый:** рекомендуется 12 или 24 часа
- **Временный:** на усмотрение; если нужно полгода — рассчитайте в часах (180 дней × 24 = 4320 часов)

#### Марка автомобиля и формат номера

- **Кириллица/латиница:** система автоматически конвертирует — можно вводить на любом языке и в любом регистре
- **ДНР номера** (без региона): через веб-интерфейс — вводить без региона; через мобильное приложение — вводить латиницей
- **Квадратные номера:** распознаются, но возможны погрешности
- **Мотоциклетные номера:** проблема с распознаванием — номер всегда сзади

#### Типы транспорта

Добавляются через «Добавить» в настройках объекта. Порядок в списке определяет, какой тип выбирается по умолчанию в мобильном приложении.

#### Чёрный список

Список автомобильных номеров, которым запрещено создание пропусков. При добавлении номера в чёрный список — пропуск на этот автомобиль создать невозможно.

**Что делать:**
1. Раздел «Объекты» → «Чёрный список»
2. Нажмите **«Добавить»**
3. Введите ГРЗ полностью: буквы, цифры, регион
4. Нажмите **«Сохранить»**

### КПП: разделение событий при едином адресе

**Проблема:** При одном адресе в системе создание нескольких КПП **не разделяет списки пропусков** для охраны — все охранники видят один общий список. КПП нигде не фигурирует в истории проездов.

**Решение через сотрудников интеграции:**

Вместо разделения по КПП — создать отдельных **сотрудников интеграции** для каждой камеры:
- «Интеграция КПП-1» → привязать к камере первого въезда
- «Интеграция КПП-2» → привязать к камере второго въезда

**Результат:** В истории событий пропуска будет видно, через какую камеру (какой КПП) проехал автомобиль.

**Где:** Раздел «Сотрудники», тип «Интеграция»

**Статус:** Решение требует дополнительной консультации с отделом разработки — уточняется возможность реализации при едином адресе.

### Ручное открытие шлагбаума: ограничения

**Ситуация:** Охранник хочет открыть шлагбаум вручную, и это должно логироваться в системе.

**Что есть в системе:**
- **Физическая кнопка** на посту охраны — открывает шлагбаум, но **ничего не фиксирует** в PASS24. Это замыкание реле, системе неизвестно.
- **Веб-интерфейс PASS24** — прямого функционала открытия шлагбаума **нет**.
- **Мобильное приложение** — открытия шлагбаума **нет**. Приложение только для пользователей (создание пропусков).
- **Веб-интерфейс камеры** — можно отправить сигнал на открытие через интерфейс камеры. Требует письмо от клиента (что ответственность за изменения в настройках — на клиенте).

**Рекомендуемый подход для логирования ручных открытий:**
1. Охранник находит нужный пропуск в PASS24 по номеру автомобиля (поиск в строке)
2. Вручную нажимает **«Приехал»** (смена статуса)
3. Это событие фиксируется с именем учётной записи охранника

**Статус разработки:** Возможность удалённого открытия шлагбаума через веб-интерфейс или приложение — на рассмотрении. Конкретных сроков нет.

### Мониторинг в реальном времени для охраны

**Текущее состояние:** В веб-интерфейсе PASS24.online **нет** реал-тайм ленты событий (кому открылось, кому закрылось, почему не открылось).

**Что доступно сейчас:**
- Поиск по номеру автомобиля в модуле «Пропуска» — охранник может найти конкретный пропуск и увидеть его статус
- Ручная смена статуса с фиксацией в журнале

**Статус разработки:** В планах — онлайн-поток с камер с отображением событий (белый список, не в белом списке) в веб-интерфейсе. Конкретные сроки и партнёр по интеграции не определены.

### Отслеживание ночной парковки

**Задача:** Определить, чей автомобиль остался на территории после 22:00 (для выставления счёта за ночную парковку).

**Решение через отчёты:**
1. Выгрузите экспорт событий пропусков за нужный период
2. В отчёте есть столбец **«Время нахождения на территории»** — разница между событиями «Приехал» и «Уехал»
3. Отфильтруйте в Excel по времени нахождения — найдите автомобили, проведшие на территории более нужного порога

**Ограничение:** Автоматической выгрузки нет (функция в разработке). Пока — вручную раз в месяц или по запросу.

---

### Спецтранспорт (скорая, пожарная)

**Ситуация:** Пожарная или скорая помощь должна въехать автоматически.

**Текущее состояние:** Автоматического разрешения для спецтранспорта нет. Причина: нет интеграции с базой ЕМИАС. Кроме того, форматы спецномеров пересекаются с обычными (4 цифры + 2 буквы) — автоматическое разрешение привело бы к ложным срабатываниям.

**Решение:** Ручное открытие охраной (физическая кнопка или через камеру). При расследовании инцидентов — лог будет только в системе камеры, не в PASS24.

### Модуль Рассылка

**Назначение:** Массовая отправка push-уведомлений пользователям мобильного приложения.

**Типы рассылки:**
- **Пользователям по адресам** — всем пользователям по выбранному адресу (при одном адресе = всем)
- **Конкретным пользователям** — например, уведомить должника о задолженности
- **Пользователям по объектам** — для мультиобъектных тарифов

**Что делать:**
1. Нажмите **«Создать»**
2. Выберите тип рассылки
3. Введите заголовок и текст
4. Нажмите **«Сохранить»**

**Результат:** Push-уведомление приходит в приложение. Если текст не умещается — пользователь открывает его в ленте событий приложения.

## Часто задаваемые вопросы (FAQ)

### Вопрос 1: Можно ли открыть шлагбаум вручную через веб-интерфейс PASS24?

**Ответ:** Нет. В веб-интерфейсе PASS24.online нет функционала прямого открытия шлагбаума. Варианты: физическая кнопка на посту охраны (не логируется), веб-интерфейс камеры (требует отдельный доступ), или ручная смена статуса пропуска охраной (логируется в PASS24).

---

### Вопрос 2: Как посмотреть лог: кому открылся/не открылся шлагбаум?

**Ответ:** В реальном времени такого лога в PASS24 нет. Ретроспективно — выгрузите экспорт событий из раздела «Пропуска». В отчёте будут все события с датой, временем, пользователем и инициатором. Если открытие было ручным через физическую кнопку — оно нигде не зафиксируется.

---

### Вопрос 3: Как полностью заблокировать арендатора-должника?

**Ответ:** Двухшаговая процедура:
1. В разделе «Пропуска» — включить все типы в фильтрах, выбрать пользователя, режим массового закрытия → закрыть все пропуска.
2. В разделе «Пользователи» — заблокировать пользователя (запрет создания новых пропусков).

Порядок шагов практически не важен. Главное — убедиться, что в фильтрах включены все типы (постоянные, временные, разовые).

---

### Вопрос 4: Как разделить списки пропусков для охраны разных КПП при одном адресе?

**Ответ:** Прямое разделение по КПП при одном адресе не работает — охранники будут видеть общий список. Альтернативное решение: создать отдельных сотрудников интеграции для каждой камеры (Интеграция КПП-1, Интеграция КПП-2) — тогда в событиях пропуска будет видно, через какой КПП проехал автомобиль. Вопрос разделения видимых списков — уточняется с разработкой.

---

### Вопрос 5: Как правильно создать постоянные пропуска для сотрудников объекта (50-100 человек)?

**Ответ:** Создайте группу «Сотрудники» в разделе «Пользователи», добавьте каждого сотрудника как пользователя с привязкой к этой группе и создайте на каждого постоянный пропуск. Не используйте одного фиктивного «арендатора» для всех — это усложняет статистику и управление.

Массовая загрузка через Excel возможна, но без назначения группы — придётся дополнительно расставлять вручную.

---

### Вопрос 6: Нужно ли подтверждение охранника при создании пропуска?

**Ответ:** Зависит от настройки в разделе «Объекты». По умолчанию для сотрудников — «По запросу». Чтобы пропуска охранника или другого сотрудника сразу становились активными, нужно поменять настройку на «Разрешить».

---

### Вопрос 7: В чём разница между разовым и временным пропуском?

**Ответ:** Разовый — закрывается после одного полного цикла (въезд + выезд) или по истечении срока. Временный — действует в течение заданного периода, позволяя неограниченное количество въездов. Постоянный — действует бессрочно, закрывается только вручную.

---

### Вопрос 8: Что происходит с пропуском, когда его срок истёк, а машина ещё на территории?

**Ответ:** Поведение зависит от настройки в разделе «Объекты»: перевести в просроченные (камера не выпустит, ждёт ручного действия), продлить на 1 час (актуально для платного въезда), или принудительно закрыть (охрана выпускает вручную через смену статуса). Рекомендуется «принудительно закрыть».

---

### Вопрос 9: Как отследить, чей автомобиль стоит платно (после 22:00)?

**Ответ:** Через экспорт событий пропусков. В отчёте Excel есть время въезда и выезда. Отфильтруйте по времени въезда: автомобили, въехавшие в вечернее время и уехавшие на следующий день, являются кандидатами на оплату.

---

### Вопрос 10: Возможно ли автоматически пропускать скорую/пожарную?

**Ответ:** Нет. Интеграция с базой ЕМИАС не реализована. Только ручное открытие (физическая кнопка или через камеру). Это редкий случай, который пока рассматривается как исключение.

---

### Вопрос 11: Почему нельзя закрыть пропуск, находящийся в статусе «На территории»?

**Ответ:** Пропуск нельзя закрыть, пока статус не изменится на «Вне территории». Нужно вручную нажать «Уехал» в карточке пропуска, и только после этого появится кнопка «Закрыть».

---

### Вопрос 12: Данные о проездах хранятся только 31 день?

**Ответ:** Доступная для самостоятельной выгрузки — 31 день. Данные в архиве хранятся бессрочно. За более ранними данными обращайтесь в техподдержку (email или Telegram-бот) — укажите объект и нужный период.

## Типичные ошибки и их решение

| Ошибка | Причина | Решение |
|---|---|---|
| Арендатор заблокирован, но продолжает въезжать | Блокировка не закрывает существующие пропуска | Зайти в «Пропуска», включить все типы в фильтре, выбрать пользователя → массовое закрытие |
| После блокировки временные/разовые пропуска остались активными | В фильтре не были включены временные и разовые типы | Убедиться, что все галочки типов пропусков стоят перед массовым закрытием |
| Невозможно закрыть пропуск | Статус «На территории» | Вручную сменить статус на «Вне территории» через карточку пропуска, затем закрыть |
| При массовой загрузке пользователи оказались без группы | Группу нельзя назначить при Excel-импорте | Назначать группу вручную через редактирование каждого пользователя |
| Охранник не видит нужного пропуска в своём КПП | Один адрес = один общий список для всех КПП | Использовать поиск по номеру; в перспективе — решение через сотрудников интеграции по КПП |
| Отчёт не приходит | Неверный email учётной записи или запрос к слишком старому периоду | Проверить email в профиле; за данными старше 31 дня — в техподдержку |
| Система тормозит | Накопление большого количества просроченных пропусков | В настройках объекта установить «Принудительно закрыть» вместо «Перевести в просроченные» |

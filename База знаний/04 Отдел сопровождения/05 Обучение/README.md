## Рекомендуемый порядок изучения

1. **Начинающим:** [Обучение PASS24.online](./Обучение%20администраторов%20PASS24.online.md) — универсальный полный документ
2. **Настройка прав охраны:** [Поликлиника](./Обучение%20администраторов%20PASS24.online%20-%20Поликлиника.md) — лучшее описание настройки подгруппы охраны
3. **Доверенности и приглашения:** [Артека — первое обучение](./Обучение%20администраторов%20PASS24.online%20-%20Артека%20—%20первое%20обучение.md)
4. **Бизнес-парк с арендаторами:** [Сходня инжиниринг](./Обучение%20администраторов%20PASS24.online%20-%20Сходня%20инжиниринг.md) — ограничения системы и специфика работы с арендаторами
5. **Коттеджный посёлок с несколькими КПП:** [Николина](./Обучение%20администраторов%20PASS24.online%20-%20Николина.md) — тройное дублирование адресов, привязка ко всем КПП, порядок запуска крупного объекта
6. **Баланс, правила, группы адресов, лимиты:** [Кандерсон](./Обучение%20администраторов%20PASS24.online%20-%20Кандерсон.md) — лимит пропусков per user, новые модули «Группы адресов» и «Минуты», Android-проблемы
7. **Telegram-бот и нюансы пропусков:** [МедМебель](./Обучение%20администраторов%20PASS24.online%20-%20МедМебель.md) — Telegram мини-приложение, «Робот» в истории событий, закрытые пропуска по умолчанию скрыты, права охраны на «Адреса»

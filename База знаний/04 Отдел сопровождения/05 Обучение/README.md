## Рекомендуемый порядок изучения

1. **Начинающим:** [Обучение PASS24.online](./Обучение%20администраторов%20PASS24.online.md) — универсальный полный документ
2. **Настройка прав охраны:** [Поликлиника](./Обучение%20администраторов%20PASS24.online%20-%20Поликлиника.md) — лучшее описание настройки подгруппы охраны
3. **Доверенности и приглашения:** [Артека — первое обучение](./Обучение%20администраторов%20PASS24.online%20-%20Артека%20—%20первое%20обучение.md)
4. **Бизнес-парк с арендаторами:** [Сходня инжиниринг](./Обучение%20администраторов%20PASS24.online%20-%20Сходня%20инжиниринг.md) — ограничения системы и специфика работы с арендаторами

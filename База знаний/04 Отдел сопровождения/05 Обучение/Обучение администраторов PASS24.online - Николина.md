## Краткое описание

Данный документ содержит структурированное обучение по веб-интерфейсу PASS24.online на основе записи встречи от 31.10.2025 для объекта «Николина» (коттеджный посёлок, номер объекта 2180, ~300 участков, 3 КПП). В документе рассмотрены все основные модули системы: Сотрудники, Права, Пользователи, Адреса, Пропуска, Запросы, Доверенности, Объекты (настройки, лимиты, черный список, типы транспорта, КПП), Рассылка, Отчёты.

**Ключевая особенность** этого обучения — детальное описание архитектуры разделения по КПП: для 300 участков с 3 КПП необходимо создать 900 адресов (каждый участок в тройном экземпляре с пометкой КПП-1/КПП-2/КПП-3), а при одобрении запроса пользователя — привязывать его сразу ко всем трём КПП.

## Основной контент

### Введение

Обучение начинается с базовой организационной структуры системы: сначала создаётся внутренняя иерархия (сотрудники и права доступа), затем адреса — и только потом пользователи (жители) и пропуска. Такой порядок критически важен: нельзя привязать пользователей к адресам, которых ещё нет в системе.

**Рекомендуемый порядок запуска объекта «Николина»:**
1. Создать подгруппу охраны в разделе «Права»
2. Создать учётные записи сотрудников охраны (по одному на каждый КПП)
3. Создать все 900 адресов через массовую загрузку Excel (300 участков × 3 КПП)
4. Запустить пользователей — пусть сами присоединяются через запрос в мобильном приложении
5. Настроить разделение списков по КПП (отдельным созвоном с менеджером)

### Модуль «Сотрудники»

**Назначение:** Управление учётными записями администраторов системы — тех, кто имеет доступ в веб-интерфейс PASS24.online. Не путать с пользователями (жителями) — это разные разделы.

#### Создание нового сотрудника

**Что делать:**
1. Перейти в раздел «Сотрудники»
2. Нажать «Новый сотрудник»
3. Заполнить поля: имя (можно только имя), e-mail (обязательно — это логин для входа в веб-интерфейс), пароль
4. Выбрать группу — по умолчанию «Администраторы»
5. Поставить галочку напротив названия объекта (Николина)
6. Нажать «Сохранить»

**Где:** Раздел «Сотрудники» в веб-интерфейсе

**Результат:** Новый сотрудник появляется в списке и может войти в систему по e-mail и паролю

**Важно:**
- E-mail является логином для веб-интерфейса
- Сотрудник ≠ пользователь мобильного приложения. Чтобы войти в мобильное приложение, нужно дополнительно внести себя в раздел «Пользователи»
- Не удалять и не редактировать системных сотрудников: «Техподдержка», «Робот», «Интеграция», «Инженер ПНР» — это учётные записи PASS24

#### Редактирование прав конкретного сотрудника

**Что делать:**
1. Нажать «три точки» напротив нужной учётной записи
2. Выбрать «Редактировать права»
3. В появившемся окне пройтись по модулям и ограничить нужные

**Примеры ограничений:**
- Запретить доступ к модулю «Запросы» — раздел просто не будет виден
- Для охраны: разрешить «Пропуска», но ограничить создание (только разовые) и редактирование (только статус — «Приехал/Уехал»)

**Важно:** Если поставить «Только статус» у охраны — они смогут нажимать только «Приехал/Уехал». Если «Полное редактирование» — смогут также менять номер автомобиля, регион и другие данные пропуска.

#### Удаление и редактирование данных сотрудника

- Удалить: «три точки» → «Удалить»
- Редактировать данные: «три точки» → «Редактировать» (смена пароля, добавление номера телефона, смена группы)

### Модуль «Права»

**Назначение:** Управление группами прав доступа. Позволяет создавать подгруппы (например, «Охрана») с настроенными ограничениями — все сотрудники в группе автоматически наследуют её права.

#### Создание подгруппы (например, «Охрана»)

**Что делать:**
1. Перейти в раздел «Права»
2. Нажать «Создать группу», ввести название (например, «Охрана»)
3. **Нажать «Сохранить» только один раз** и подождать 10–15 секунд

**Важно:** Кнопка «Сохранить» может подвисать. Если нажать несколько раз — создастся несколько одинаковых подгрупп.

#### Добавление сотрудника в подгруппу

**Что делать:**
1. В разделе «Права» найти сотрудника (отображается по первой букве имени)
2. Перетащить его в нужную подгруппу

**Результат:** Сотрудник автоматически наследует права подгруппы

#### Настройка прав подгруппы

**Что делать:**
1. Нажать «шестерёнку» напротив подгруппы
2. Выставить настройки по модулям
3. Нажать «Сохранить»

**Важно для КПП «Николина»:** Если у вас 3 КПП — создать отдельного сотрудника охраны для каждого КПП. После настройки разделения по КПП каждый охранник будет видеть только пропуска своего КПП.

### Модуль «Пользователи»

**Назначение:** Учёт жителей (собственников участков), имеющих доступ к мобильному приложению PASS24. Пользователи могут заказывать пропуска и создавать доверенности. Доступ в веб-интерфейс у них отсутствует.

#### Способ 1: Добавление вручную

**Что делать:**
1. Нажать «Добавить»
2. Заполнить: ФИО, номер телефона (через «+7»), адрес(а)
3. Нажать «Сохранить»

**Результат:** Пользователь появляется в системе и может авторизоваться в мобильном приложении по номеру телефона

#### Способ 2: Запрос от пользователя через мобильное приложение

**Как это работает:**
1. Пользователь скачивает мобильное приложение и проходит регистрацию
2. Приложение запрашивает номер объекта — пользователь вводит **2180**
3. В разделе «Запросы» у администратора появляется запрос на присоединение
4. Администратор проверяет данные (ФИО, номер телефона, адрес участка)
5. Нажимает «Одобрить» и привязывает пользователя к адресу(ам)

**Важно для «Николина» (3 КПП):** При одобрении запроса — обязательно привязывать пользователя сразу ко **всем трём КПП** (КПП-1, КПП-2, КПП-3). Для этого в поле «Добавить адрес» выбираете все три адреса для данного дома.

Поиск нужного адреса: начните вводить номер участка (например, «222») — система покажет все три адреса этого дома с пометками КПП.

#### Способ 3: Массовая загрузка через Excel

**Что делать:**
1. Нажать «Импорт» → «Пример с пользователями»
2. Скачать шаблон, заполнить: ФИО, телефон, адрес
3. Загрузить заполненный файл

**Когда использовать:** При большом количестве участков, если есть готовая таблица с данными жителей.

#### Блокировка пользователя

**Что делать:**
1. Найти пользователя, нажать «Редактировать»
2. Перетащить ползунок блокировки в активный
3. Добавить внутренний комментарий (пользователь его не видит)
4. Нажать «Сохранить»

**Результат:** Пользователь не может создавать новые пропуска. При попытке — видит сообщение обратиться к администратору.

**Важно:** Блокировка не закрывает уже существующие активные пропуска. Для закрытия активных пропусков заблокированного пользователя: раздел «Пропуска» → фильтр по пользователю → выбрать все → «Закрыть выбранное».

#### Привязка пользователя к нескольким адресам

**Что делать:**
1. Найти пользователя, нажать «Редактировать»
2. В поле адресов добавить дополнительные адреса

**Когда использовать:** Если пользователь является собственником нескольких участков или управляет несколькими домами.

### Модуль «Адреса»

**Назначение:** Хранение адресов участков, к которым привязываются пользователи. Адрес — это точка въезда, к которой привязывается пропуск.

#### Архитектура адресов для «Николина» (3 КПП)

**Ключевой принцип:** Для разделения пропусков по КПП каждый участок должен быть создан в **тройном экземпляре** — по одному адресу на каждый КПП.

**Пример для участка №1:**
- Адрес 1: Дом 1, КПП-1
- Адрес 2: Дом 1, КПП-2
- Адрес 3: Дом 1, КПП-3

**Итого для «Николина»:** 300 участков × 3 КПП = **900 адресов**

Поле «Короткое название» — внутренняя пометка, видна только администратору. Можно использовать для любых заметок.

#### Создание адресов через массовую загрузку (рекомендуется)

**Что делать:**
1. Нажать «Импорт» → «Пример без пользователей»
2. Скачать шаблон
3. Заполнить таблицу: для каждого дома создать три строки с разными пометками КПП

**Пример заполнения Excel:**
```
Дом: 1, КПП-1
Дом: 1, КПП-2
Дом: 1, КПП-3
Дом: 2, КПП-1
Дом: 2, КПП-2
Дом: 2, КПП-3
...
```
4. Загрузить заполненный файл

**Важно:** Сначала создайте все адреса, затем начинайте добавлять пользователей.

#### Блокировка адреса

- **Блокировка всего адреса:** запрещает всем пользователям этого адреса создавать пропуска
- **Блокировка конкретного пользователя на адресе:** нажать «замочек» напротив пользователя — запрещает только ему, остальные продолжают работать

### Модуль «Пропуска»

**Назначение:** Основной рабочий модуль — отображение всех созданных пропусков, управление статусами, поиск и фильтрация.

#### Типы пропусков

| Тип | Описание |
|-----|----------|
| Разовый | Один въезд + один выезд, после чего автоматически закрывается |
| Временный | Многократный въезд/выезд в течение указанного срока |
| Постоянный | Бессрочный, требует ручного или запросного закрытия |

#### Создание пропуска (администратором)

**Что делать:**
1. Нажать «Новый пропуск»
2. Выбрать адрес → пользователь подтянется автоматически (если он один)
3. Выбрать тип пропуска
4. Ввести марку и номер автомобиля (марка ищется на русской и английской раскладках)
5. При необходимости добавить несколько гостей — нажать «Добавить гостя»
6. Нажать «Сохранить»

**Важно:** Пользователи также могут создавать пропуска самостоятельно через мобильное приложение.

#### Управление статусом пропуска

- «Приехал» → статус «На территории»
- «Уехал» → статус «Вне территории»
- Разовый пропуск после «Уехал» **закрывается автоматически**
- Постоянный и временный пропуска: для закрытия сначала нужен статус «Вне территории», затем раскрыть окно действий → «Закрыть»

#### Поиск пропусков

- По номеру автомобиля (частичный ввод работает, но может захватить пропуска с совпадающим регионом — вводите полный номер для точного результата)
- По пользователю (через фильтры)

#### Массовое закрытие пропусков

**Когда использовать:** При блокировке пользователя с активными пропусками

**Что делать:**
1. В разделе «Пропуска» открыть фильтры
2. Выбрать нужного пользователя → нажать «Применить»
3. Нажать «Выбрать все найденные»
4. Нажать «Закрыть выбранное»

**Ограничение:** На странице отображается не более 60 пропусков одновременно.

#### Тактика «3 пропуска» для объектов с несколькими КПП

Если гость не знает, через какое КПП въедет — пользователь может создать три пропуска (по одному на каждый КПП). Неиспользованные разовые пропуска автоматически закроются по истечении срока действия.

**Важно:** Эта тактика создаёт нагрузку на систему и не рекомендуется как основной подход. Лучше сразу объяснить жителям, через какое КПП едет гость.

#### Выгрузка отчёта по событиям въезда/выезда

**Что делать:**
1. В разделе «Пропуска» нажать «Экспортировать события пропусков» (иконка облака)
2. Выбрать адрес/пользователя или оставить пустым (выгрузится по всем)
3. Нажать «Отправить»

**Результат:** На почту администратора придёт Excel с данными: номер пропуска, номер машины, дата въезда, дата выезда, кем инициировано, время на территории.

**Ограничение:** Выгрузка только за последние 31 день. Более глубокий архив — по запросу в техподдержку PASS24.

### Модуль «Запросы»

**Назначение:** Обработка входящих запросов от пользователей мобильного приложения.

#### Типы запросов

| Тип | Описание |
|-----|----------|
| Запрос на присоединение | Новый пользователь хочет присоединиться к объекту |
| Запрос на пропуск | Запрос на создание пропуска (временного или постоянного) |
| Запрос на доверенность | Пользователь хочет оформить доверенность |
| Сообщение в УК | Произвольное сообщение от пользователя |

#### Обработка запроса на присоединение

**Что делать:**
1. В разделе «Запросы» найти новый запрос (статус «На рассмотрении»)
2. Проверить данные: ФИО, номер телефона, адрес участка
3. Если данных хватает → «Одобрить», выбрать адрес(а) для привязки
4. Если данных не хватает → «Отклонить», указать причину

**Важно для «Николина»:** При одобрении запроса привязывать пользователя сразу ко **всем трём КПП** его участка (все три адреса с пометками КПП-1, КПП-2, КПП-3). Начните набирать номер участка в поле поиска адреса — система покажет все три адреса.

#### Постоянные пропуска всегда идут через запросы

Пользователи не могут создать постоянный пропуск напрямую — он всегда требует одобрения администратора. Это встроенная логика системы.

### Модуль «Доверенности»

**Назначение:** Предоставление временного доступа в мобильное приложение другому лицу от имени собственника. По истечении срока доверенности пользователь и все его пропуска автоматически закрываются.

#### Создание доверенности

**Что делать:**
1. Перейти в раздел «Доверенности»
2. Нажать «Добавить»
3. Заполнить: собственник (от чьего лица доверенность), период активности, ФИО доверенного лица, номер телефона
4. Нажать «Сохранить»

**Результат:** С момента начала действия доверенности указанное лицо получает доступ в мобильное приложение и может создавать пропуска.

**Важно:**
- По истечении срока всё закрывается автоматически (доступ + пропуска)
- Администратор может аннулировать доверенность досрочно
- Пользователь-собственник не может сам закрыть доверенность раньше срока
- Можно ограничить: запретить доверенным лицам создавать пропуска (в настройках объекта)

---

### Модуль «Объекты» (Настройки)

**Назначение:** Централизованная настройка всего объекта: лимиты, правила работы с пропусками, черный список, типы транспорта, разделение по КПП.

#### Контактный номер телефона

В разделе «Объекты» → ваш объект → поле «Номер телефона» — это номер, который жители видят в мобильном приложении для связи с УК. Можно изменить на актуальный или на нерабочий, если не хотите получать звонки.

#### Опции при создании пропуска

Дополнительные пометки (например, «разгрузка/погрузка»), которые пользователь может указать при создании пропуска.

**Что делать:** Если опция не нужна — перетащить ползунок в неактивный. У пользователей она перестанет отображаться.

**Важно:** Список опций нельзя редактировать или дополнять — только активировать/деактивировать существующие.

#### Раздел «Работа с пропусками» — Лимиты

Позволяет установить максимальное количество одновременно активных пропусков.

**Важно:** Лимит распространяется на **всю систему**, а не на конкретного пользователя или адрес. Используйте осторожно — при превышении никто не сможет создать пропуск. Как правило, лимиты применяют платные въезды (бизнес-центры, склады).

#### Раздел «Работа с пропусками» — Типы пропусков

| Настройка | Варианты | Рекомендация для «Николина» |
|-----------|----------|----------------------------|
| Постоянный пропуск | Разрешить запрос / Запретить запрос | Оставить «Разрешить запрос» — всегда требует одобрения |
| Временный пропуск | Разрешить / По запросу / Запретить | По вашему выбору |
| Разовый пропуск | Запретить нельзя | — |

#### Раздел «Работа с пропусками» — Обязательные поля

- **Марка автомобиля** — если активна, пропуск не создастся без марки
- **Формат номера автомобиля** — если активна, номер должен соответствовать формату

**Важно для ДНР-номеров:** Формат ДНР-номеров не содержит региона (например, «Н263АА ДНР»). Создавать такие пропуска нужно на **английской раскладке** — тогда система позволит указать номер без региона.

#### Раздел «Работа с пропусками» — Автоматический перевод пропуска по истечении срока

Что происходит с пропуском, если его срок истёк, а статус «На территории»:

| Вариант | Описание |
|---------|----------|
| В просроченные | Висит в системе как просроченный до смены статуса |
| Продление на час | Каждый час продлевается до выезда |
| Принудительное закрытие | Закрывается вне зависимости от статуса |

**Рекомендация:** Выбирать «Принудительное закрытие» или «Продление на час» — просроченные пропуска накапливаются и замедляют систему.

#### Раздел «Работа с пропусками» — Максимальный срок действия

Устанавливается в часах:
- Разовый пропуск — как правило, 24 часа
- Временный пропуск — по усмотрению (можно задать месяц, полгода, год)

Конвертация: используйте Google для перевода дней в часы (например, 30 дней = 720 часов).

#### Раздел «Работа с запросами»

- Запрос на присоединение можно отключить (если хотите сами добавлять всех пользователей)
- Сообщения в УК можно отключить (если не хотите получать переписку от жителей)
- Доверенности для пользователей можно отключить

#### Раздел «Доверенные лица»

- Можно установить максимальный срок действия доверенности
- Можно запретить доверенным лицам создавать пропуска

#### Чёрный список

**Что делать:**
1. Нажать «Добавить», ввести ГРЗ (госномер автомобиля)

**Результат:** При попытке создания пропуска на этот номер — восклицательный знак с предупреждением. При попытке сохранить — ошибка «Номер в чёрном списке».

#### Типы транспорта

Позволяет создать градацию транспорта (например, «Легковой», «Грузовой»).

**Что делать:**
1. Нажать «Добавить»
2. Ввести наименование типа транспорта и номер по порядку (для сортировки в выпадающем списке)

**Важно:** При наличии нескольких типов транспорта пользователь обязан выбрать тип при создании пропуска (по умолчанию подставляется тип с сортировкой №1).

**Для «Николина»:** Рекомендуется создать «Легковой» и «Грузовой». Если гость указал неверный тип — отклонить запрос с комментарием «Укажите тип транспорта».

#### КПП — разделение списков

**Что это такое:** Настройка, при которой охрана на каждом КПП видит только пропуска, предназначенные для въезда через их КПП. Также разделяются белые списки для камер автораспознавания.

**Как реализовать для «Николина» (3 КПП):**

1. Создать адреса в тройном экземпляре (дом 1 КПП-1 / дом 1 КПП-2 / дом 1 КПП-3 и т.д. для всех 300 домов = 900 адресов)
2. Создать отдельного сотрудника охраны для каждого КПП
3. Настройку разделения списков выполнить **отдельным созвоном с менеджером PASS24**

**Важно:** Если разделения нет — белые списки на все камеры общие, охрана на всех КПП видит один общий список пропусков.

## Особенности объекта «Николина»: роль охраны и планшетов

**Как работает охрана на КПП:**
- Охрана работает через **веб-интерфейс в браузере** на планшете (а не через мобильное приложение)
- Планшеты уже преднастроены: на рабочем столе вынесена ссылка на облако
- Охрана авторизуется один раз — система не выкидывает из сессии
- Задача охраны: просматривать список пропусков, искать по номеру автомобиля, нажимать «Приехал/Уехал»

**Чего охрана НЕ может через мобильное приложение:**
- Мобильное приложение — только для **пользователей (жителей)**, а не для охраны
- Через мобильное приложение можно только создавать пропуска и доверенности
- Менять статус пропуска («Приехал/Уехал») через мобильное приложение **нельзя**

## Часто задаваемые вопросы (FAQ)

### Вопрос 1: В разделе «Сотрудники» мы создаём КПП и охрану?

**Ответ:** Нет. В «Сотрудниках» создаются только учётные записи администраторов системы (тех, кто управляет веб-интерфейсом). КПП — это разделение в настройках объекта. Охрана добавляется как сотрудник с ограниченными правами.

---

### Вопрос 2: Группы в «Правах» — это как отдельные дома?

**Ответ:** Нет. Группы в «Правах» — это уровни полномочий (например, «Администраторы», «Охрана»). Дома и участки создаются в модуле «Адреса».

---

### Вопрос 3: Если сотрудник добавлен как пользователь мобильного приложения — он может войти в веб-интерфейс?

**Ответ:** Нет. Это разные учётные записи. Вход в веб-интерфейс — по e-mail через раздел «Сотрудники». Вход в мобильное приложение — по номеру телефона через раздел «Пользователи». Чтобы иметь оба доступа, нужно быть в обоих разделах.

---

### Вопрос 4: Может ли охрана работать через мобильное приложение, а не планшет?

**Ответ:** Нет. Смена статуса пропуска («Приехал/Уехал») доступна только в веб-интерфейсе. Мобильное приложение — только для создания пропусков пользователями. Охрана должна использовать браузер (лучше — планшет из-за размера экрана).

---

### Вопрос 5: Как быть, если гость не знает, через какое КПП въедет?

**Ответ:** Есть два варианта:
1. Пользователь создаёт 3 пропуска — по одному на каждый КПП. Неиспользованные разовые автоматически закроются по истечении срока.
2. Объяснить жителям важность указания КПП заранее — это снизит нагрузку на систему.

---

### Вопрос 6: Лимит активных пропусков действует на пользователя или на всю систему?

**Ответ:** На **всю систему**. Если поставить лимит 50 разовых пропусков — при попытке создать 51-й появится ошибка у всех: и у администратора, и у пользователей. Для коттеджного посёлка лимиты, как правило, не нужны.

---

### Вопрос 7: Что делать с пропусками с грязными номерами, которые не распознала камера?

**Ответ:** Камера может не распознать номер (грязь, снег). В этом случае пропуск с «Приехал» не сменится на «Уехал» автоматически. Решение — выбрать вариант «Принудительное закрытие» или «Продление на час» в настройках объекта для пропусков с истёкшим сроком.

---

### Вопрос 8: Можно ли привязать пользователя к нескольким адресам?

**Ответ:** Да. При редактировании пользователя можно добавить несколько адресов. Это нужно, например, для собственника двух участков или управляющего несколькими домами.

---

### Вопрос 9: Разовый пропуск — можно заехать несколько раз в течение 24 часов?

**Ответ:** Нет. Разовый пропуск — один въезд и один выезд. После нажатия «Уехал» пропуск автоматически закрывается. Для многократных въездов в течение срока нужен временный пропуск.

---

### Вопрос 10: Как сделать, чтобы камеры на разных КПП видели разные белые списки?

**Ответ:** Это настраивается при разделении по КПП. Нужно:
1. Создать адреса в тройном экземпляре (с пометками КПП-1/2/3)
2. Создать отдельного сотрудника охраны для каждого КПП
3. Связаться с менеджером PASS24 для настройки разделения списков по камерам в онлайн-формате

## Типичные ошибки и их решение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Создалось несколько одинаковых подгрупп в «Правах» | Кнопка «Сохранить» была нажата несколько раз, пока система подвисала | Удалить лишние подгруппы; при следующем создании нажимать один раз и ждать 10–15 сек |
| Пользователь не может войти в мобильное приложение | Пользователь создан только в «Сотрудниках», но не в «Пользователях» | Добавить пользователя в раздел «Пользователи» с его номером телефона |
| При создании пропуска ошибка «Превышен лимит» | Установлен глобальный лимит активных пропусков | Снять или увеличить лимит в настройках объекта → «Работа с пропусками» |
| Пропуск не закрывается | Статус «На территории» — закрыть нельзя | Сначала нажать «Уехал» → статус «Вне территории» → затем «Закрыть» |
| Пропуск с ДНР-номером не создаётся | Система требует регион | Вводить номер на английской раскладке — тогда формат без региона принимается |
| Пропуск на номер в чёрном списке создаётся с предупреждением | Пользователь игнорирует восклицательный знак | При нажатии «Сохранить» всё равно выйдет ошибка — пропуск не создастся |
| Таблица Excel с адресами/пользователями не загружается | Изменена структура столбцов в шаблоне | Использовать только оригинальный шаблон, не менять порядок столбцов |

## Контрольный чек-лист запуска объекта

### Организационная структура
- [ ] Создана подгруппа «Охрана» в разделе «Права»
- [ ] Настроены права подгруппы охраны (доступ к пропускам, тип редактирования)
- [ ] Созданы учётные записи сотрудников охраны (по одной на каждый КПП)
- [ ] Сотрудники охраны перенесены в подгруппу «Охрана»

### Адреса
- [ ] Сформирована Excel-таблица со всеми 300 участками × 3 КПП = 900 строк
- [ ] Все адреса загружены через массовую загрузку
- [ ] Структура адресов: «Дом [номер], КПП-1/2/3»

### Настройки объекта
- [ ] Выбрана политика для просроченных пропусков (рекомендуется «Принудительное закрытие»)
- [ ] Настроены типы транспорта (минимум «Легковой» и «Грузовой»)
- [ ] Деактивированы ненужные опции при создании пропуска
- [ ] Установлен максимальный срок разового пропуска (рекомендуется 24 часа)
- [ ] Проверен контактный номер телефона в объекте

### Пользователи
- [ ] Жители проинформированы о номере объекта (2180) для регистрации в приложении
- [ ] Настроена обработка входящих запросов (одобрение с привязкой ко всем 3 КПП)

### КПП и камеры
- [ ] Запланирован созвон с менеджером PASS24 для настройки разделения списков по КПП
- [ ] Планшеты на КПП проверены (ссылка на рабочем столе, авторизация выполнена)

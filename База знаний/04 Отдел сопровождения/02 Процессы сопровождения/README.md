# Процессы сопровождения

## Описание подраздела

Данный подраздел содержит регламенты и процедуры работы менеджеров по сопровождению клиентов компании PASS24.online. Включает основные процессы работы с клиентами, процедуры изменения условий договоров и работы с реестрами.

#### [Вторая линия поддержки и платный выезд](./Интервью/2%20линия%20поддержки.md)

**Тип:** Регламент / Справочник (разбор интервью)

Включены контекст в базе знаний, предложения по улучшению, непокрытые вопросы (в т.ч. по рекомендациям ИИ) и уровни контроля.

**Разбор интервью: закупка на стороне компании, доставка планшетов**

**Тип:** Регламент / Справочник (разбор интервью)  
**Для кого:** Менеджеры по сопровождению, ответственные за закупку; ОП; руководитель ОС; бухгалтерия

Описывает процесс закупки прочего оборудования (iVideon, щитки и т.д.) на стороне компании: задача ОП → запрос счёта у поставщика → согласование и оплата → приёмка и закрывающие документы (ЭДО). Отдельно — определение ответственных за закупку (ТКП, подрядчик vs компания) и доставка подарочных планшетов клиентам через СДЭК. Включены контекст в базе знаний, предложения по улучшению, непокрытые вопросы и уровни контроля.

## Рекомендуемый порядок изучения

1. **ОС вводное** — общее понимание работы отдела
2. **ПРОЦЕССЫ МЕНЕДЖЕРА ПО СОПРОВОЖДЕНИЮ КЛИЕНТОВ** — детальное изучение всех 20 процессов
3. **Процесс повышения АП** — работа с абонентской платой
4. **Процесс расторжения договора** — работа с расторжением договоров
5. **Процесс обучения и реализация проекта** (интервью) — обучение после создания облака, ОПД, претензии по монтажу
6. **Работа с дебиторской задолженностью** (интервью) — еженедельный сбор ДЗ, обзвон, дубликаты счетов, эскалация
7. **Вторая линия поддержки и платный выезд** (интервью) — Admin24 → Bitrix24, комментарии по стадиям, апсейл на ОП, платный выезд инженера
8. **Закупка прочего оборудования** (интервью) — закупка на стороне компании (iVideon, щитки), ТКП и определение ответственных, доставка подарочных планшетов (СДЭК)

# Спринты и процессы

## Описание подраздела

Регламенты планирования, проведения и завершения спринтов, а также связанные процессы (стендапы, ретроспективы, Definition of Done).

## Документы

| Документ | Назначение |
|----------|------------|
| [Регламент спринтов](./Регламент%20спринтов.md) | Общие правила спринтов, длительность, события, роли |
| [Планирование спринта](./Планирование%20спринта.md) | Backlog, цели спринта, оценки, чек-лист планирования |
| [Definition of Done](./Definition%20of%20Done.md) | Критерии готовности к сдаче задачи |

## Рекомендуемый порядок изучения

1. Регламент спринтов — для понимания общего цикла
2. Планирование спринта — перед каждым планированием
3. Definition of Done — при создании и приёмке задач

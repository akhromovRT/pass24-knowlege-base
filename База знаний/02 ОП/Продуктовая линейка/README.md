## Описание раздела

Данный раздел содержит подробное описание всех продуктов компании PASS24.online, входящих в комплексное решение для автоматизации управления доступом. Каждый документ описывает отдельный продукт с детальным функционалом, техническими характеристиками, преимуществами и сценариями применения.

## Связь между продуктами

Все продукты являются частью комплексного решения PASS24.online:

- **PASS24.online** — базовая платформа, основа всего решения
- **PASS24.Key** — мобильное приложение для идентификации пользователей
- **PASS24.auto** — модуль для автоматизации проезда транспорта
- **PASS24.admin** — веб-интерфейс для управления всей системой

Продукты могут использоваться как отдельно, так и в комбинации в зависимости от потребностей клиента.

## Тарифные планы

Актуальная тарифная сетка PASS24 — 4 SaaS-тарифа:

- **Базовый** (10 990 ₽/мес) — 1 объект с контролем въезда через распознавание номеров, при 6-месячной подписке ПАК за 1 ₽ по акции
- **Стандартный** ★ (14 990 ₽/мес) — ЖК и коттеджные посёлки с полноценной пропускной системой и интеграцией со СКУД
- **Профессиональный** (24 990 ₽/мес) — объекты с промышленным учётом жителей, платным въездом и API (Read/Write + Webhooks)
- **Мультиобъектный** (от 48 990 ₽/мес) — УК с портфелем объектов: единый кабинет, консолидированная отчётность, CSM

Полная матрица функций, лимитов, политика сверхлимита и SLA — в эталонном документе [Тарифы PASS24](./Тарифы%20PASS24.md).

Устаревшее описание тарифов старого сайта (Стандарт / Авто / СКУД / Авто + СКУД) осталось в документе [Структура сайта pass24online.ru](../../03%20Маркетинг/Структура%20сайта%20pass24online.ru.md) и больше не используется для новых коммерческих предложений.

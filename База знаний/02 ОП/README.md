## Рекомендуемый порядок изучения для новых менеджеров

1. **Инструкция менеджера по продажам** — практическое руководство для начала работы
2. **Методология продаж PASS24** — общее понимание подхода
3. **Целевые клиенты и критерии квалификации** — понимание целевой аудитории
4. **Продуктовая линейка** — знание продуктов компании
5. **Воронки продаж** — детальные процессы работы со сделками
6. **Работа с возражениями** — практические навыки

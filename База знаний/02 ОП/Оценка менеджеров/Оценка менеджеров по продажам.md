## Краткое описание

Данный документ описывает единый подход к оценке работы менеджеров по продажам компании PASS24.online. Оценка основана на методологии продаж PASS24, работе в CRM Bitrix24 и практических требованиях из «Инструкции менеджера по продажам». Документ задаёт прозрачные критерии, шкалу оценки и порядок проведения оценки, чтобы связать ежедневную работу менеджера с целями компании и качеством сервиса.

## Предварительные требования

**Необходимые знания:**
- Понимание методологии продаж PASS24 (см. документ `Методология продаж PASS24`)
- Знание «Инструкции менеджера по продажам» и базовых обязанностей менеджера

**Необходимые материалы/ресурсы:**
- Отчёты CRM по каждому менеджеру за оцениваемый период
- Записи звонков (выборочно) для контроля качества
- План продаж и целевые показатели (KPI) отдела на период

## Основной контент

### Цели оценки менеджера по продажам

**Основные цели:**
- Связать ежедневные действия менеджера с результатами по воронке и выручке
- Обеспечить единый, понятный и прозрачный стандарт оценки для всей команды
- Выявлять зоны роста каждого менеджера (навыки, дисциплина, работа в CRM)
- Поддерживать культуру регулярной обратной связи и развития, а не «разбор полётов»

### Принципы оценки

- **Прозрачность:** критерии и шкала оценки известны менеджеру заранее
- **Регулярность:** оценка проводится по фиксированному циклу (например, ежемесячно)
- **Опора на данные:** максимум показателей берётся из CRM Bitrix24 и фактических результатов
- **Баланс качественных и количественных критериев:** важно не только «сколько сделок», но и «как» ведётся работа
- **Фокус на развитии:** по результатам оценки формируется план развития, а не только «оценка ради оценки»

## Пошаговая инструкция по проведению оценки

### Шаг 1. Определить период и подготовить данные

**Что делать:**
1. Определите период оценки (месяц / квартал).
2. Сформируйте отчёты CRM по каждому менеджеру:
   - Количество новых лидов и сделок
   - Конверсии по ключевым этапам воронок (облако / оборудование)
   - Скорость реакции на лиды (time-to-first-contact)
   - Количество и длительность звонков
   - Количество задач, просроченных и выполненных в срок
3. Подготовьте доступ к записям звонков для выборочной проверки качества.

**Результат:** есть полный набор данных по каждому менеджеру за период.

---

### Шаг 2. Оценить дисциплину и работу в CRM

**Что оценивается:**
- Соблюдение рабочего графика и правил («Инструкция менеджера по продажам»)
- Работа в CRM: отсутствие «висящих» лидов, своевременные комментарии, задачи
- Скорость реакции на лиды (Speed-to-Lead)

**Пример критериев:**

| Критерий | Описание | Источник данных |
|----------|----------|-----------------|
| Пунктуальность и присутствие | Опоздания, соблюдение «часов продаж», участие в РГ | Табель, отметки присутствия, наблюдения руководителя |
| Работа в CRM | Все лиды и сделки ведутся в CRM, нет «забытых» стадий | Отчёты CRM, выборочная проверка сделок |
| Скорость реакции на лиды | Время от поступления лида до первого контакта | Отчёты CRM по time-to-first-contact |

**Шкала оценки (пример 1–5):**
- **5** — требования выполняются стабильно, нарушений практически нет
- **4** — в целом выполняется, бывают единичные отклонения
- **3** — есть систематические недочёты, требует контроля
- **2** — дисциплина и работа в CRM неудовлетворительны
- **1** — критический уровень, отсутствие базовой дисциплины

---

### Шаг 3. Оценить воронку продаж и результаты

**Что оценивается:**
- Объём входящих и обработанных лидов
- Конверсии между ключевыми стадиями воронки (см. «Методология продаж PASS24»)
- Достигнутые результаты по выручке/сделкам

**Ключевые показатели (пример):**

| Показатель | Описание |
|-----------|----------|
| Количество новых лидов | Сколько лидов менеджер получил и принял в работу |
| Конверсия лид → встреча / презентация | Доля лидов, доведённых до встречи или демонстрации |
| Конверсия встреча → КП / предложение | Доля встреч, по которым отправлено КП |
| Конверсия КП → договор / оплата | Доля предложений, завершившихся подписанием и оплатой |
| Выполнение плана по выручке / сделкам | % выполнения плана за период |

**Как оценивать:**
- Сравните показатели менеджера с:
  - Целевыми значениями (план отдела)
  - Средними показателями по команде
- Оцените по шкале 1–5 с комментариями (в чём сильные и слабые стороны).

---

### Шаг 4. Оценить качество работы с клиентами

**Что оценивается:**
- Использование методологии (SPIN, CHAMP, Challenger и др.) в реальных диалогах
- Качество презентации: фокус на ценности, а не на функциях
- Работа с возражениями и закрытие сделки

**Действия:**
1. Выберите 2–5 звонков/диалогов менеджера за период (в идеале — на разных этапах воронки).
2. Прослушайте/проанализируйте их по чек-листу:

**Чек-лист качества диалога (пример):**
- [ ] Менеджер задаёт вопросы по ситуации клиента (Situation)
- [ ] Выявляет проблемы и «боли» (Problem)
- [ ] Обсуждает последствия проблем (Implication)
- [ ] Формирует ценность решения (Need-payoff)
- [ ] Говорит на языке выгод для клиента, а не только функций
- [ ] Аккуратно, но уверенно ведёт клиента к следующему шагу

**Результат:** оценка качества коммуникации (1–5) и конкретные примеры, которые можно использовать в обучении.

---

### Шаг 5. Оценить развитие и вовлечённость

**Что оценивается:**
- Участие в РГ, тренингах, обсуждениях
- Инициативность: предложения по улучшению скриптов, процессов, материалов
- Готовность делиться опытом с командой

**Пример критериев:**

| Критерий | Вопросы для оценки |
|----------|--------------------|
| Участие в обучении | Посещает ли РГ и тренинги, активно ли участвует? |
| Инициативность | Предлагает ли идеи по улучшению методов, скриптов, материалов? |
| Командное взаимодействие | Помогает ли коллегам, делится ли удачными кейсами? |

Оцените каждый критерий по шкале 1–5 и зафиксируйте примеры поведения.

---

### Шаг 6. Сформировать итоговую оценку и план развития

**Что делать:**
1. Сведите оценки по блокам в единую таблицу:

| Блок | Вес (пример) | Оценка (1–5) | Взвешенный балл |
|------|--------------|--------------|-----------------|
| Дисциплина и CRM | 25% |   |   |
| Воронка и результаты | 35% |   |   |
| Качество работы с клиентами | 25% |   |   |
| Развитие и вовлечённость | 15% |   |   |

2. Рассчитайте итоговый балл и кратко опишите результат (например, «уровень А / B / C»).
3. Сформулируйте 2–3 ключевые зоны роста и 2–3 сильные стороны.
4. По каждой зоне роста определите конкретные действия (что делать менеджеру и что делает руководитель).

**Результат:** прозрачная итоговая оценка + понятный план развития на следующий период.

## Примеры и кейсы

### Пример 1: Менеджер с хорошими результатами, но слабой дисциплиной

**Ситуация:**
- Высокая конверсия по воронке и выполнение плана
- При этом есть опоздания, просроченные задачи в CRM, не все лиды доведены до финала

**Вывод:**
- Важно сохранить сильные стороны (умение закрывать сделки), но подтянуть дисциплину и работу в CRM

**Решение:**
- Зафиксировать в плане развития конкретные требования по дисциплине и дедлайны
- Ввести дополнительный контроль по задачам в CRM на следующий период

---

### Пример 2: Менеджер с хорошей дисциплиной, но слабой конверсией

**Ситуация:**
- Все задачи в CRM выполняются, опозданий нет
- Низкая конверсия из лида во встречу и из встречи в КП

**Вывод:**
- Основная проблема — навыки коммуникации и квалификации лида

**Решение:**
- Прослушать выборку звонков, провести индивидуальное обучение по методологии SPIN и работе с возражениями
- Зафиксировать в плане развития прохождение конкретных тренингов и отработку скриптов

## Критерии успеха

**Оценочный процесс считается успешным, если:**
- Менеджер понимает, по каким критериям его оценивают и с чем связана его оценка
- Есть конкретный, понятный план развития по итогам оценки
- От периода к периоду видно улучшение показателей (воронка, дисциплина, качество работы)
- Оценка используется не только для «контроля», но и как инструмент развития команды

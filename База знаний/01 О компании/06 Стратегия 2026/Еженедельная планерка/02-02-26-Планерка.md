### 2. Цель 1: Ускорить продажу PASS24.Cloud

**KPI:** Цикл сделки < 14 дней

**Обсуждение:**
- **2.1 Средний цикл сделки:** За декабрь-январь создано ~40 новых сделок. Требуется детальный анализ в Битриксе за ноябрь, декабрь и январь с разделением на категории (закрытые менее чем за 2 недели и более 2 недель)
- **2.2 % сделок закрыто менее чем за 14 дней:** За декабрь-январь: 2 из ~40 сделок (5%). За январь: 2 сделки соответствуют целевому показателю. Одна из них — облачная, вторая — апсейл от Максима
- **2.3 Узкие места в процессе продаж:** 
  - Клиенты рассматривают решение в комплексе (оборудование + облако) и тратят много времени на согласование покупки оборудования
  - Сделки затягиваются, потому что клиенты приходят за оборудованием, а облако покупают уже по факту
  - **Решение найдено:** Акция по включению стоимости оборудования в абонентскую плату — эффективный рычаг для ускорения продаж
  - Онлайн-презентации значительно ускоряют процесс заключения сделок
- **2.4 Статус цели:** 🟡 Есть риски — только 5% сделок закрываются быстро, необходимо увеличить до 50%

**Вывод:** Выявлен эффективный инструмент ускорения (акция), но требуется масштабирование. Запланированы индивидуальные встречи с менеджерами по продажам для детального разбора сделок

### 3. Цель 2: Упаковать стандарт Cloud для КП

**KPI:** 1 оффер · 1 сценарий · 1 типовое КП

**Обсуждение:**
- **3.1 % использования стандартного оффера:** Комплексное коммерческое предложение с тремя вариантами отправляется практически в 100% случаев. Это позволяет клиенту сразу видеть все опции и ускоряет процесс выбора
- **3.2 % использования типового сценария:** Типового сценария внедрения пока нет (оценка "ноль"). Требуется создать стандартный сценарий с инструкциями для подрядчиков и преднастроенным оборудованием
- **3.3 Шаги по упаковке стандарта за неделю:** 
  - Процесс продаж выстроен: звонок → КП с тремя вариантами → презентация с детальным обсуждением вариантов
  - Варианты КП: 1) Тариф "Стандарт" с планшетом; 2) Подключение по акции с распознаванием лиц; 3) Тариф "Проф" с полной покупкой оборудования
  - Задача: создать типовой сценарий внедрения
- **3.4 Статус цели:** 🟡 (желтый — под угрозой)

**Вывод:** Оффер работает эффективно (100% использование), но отсутствие типового сценария внедрения — узкое место. Требуется разработка стандартного сценария с инструкциями для подрядчиков.

### 4. Цель 3: Построить повторяемую машину продаж

**KPI:** Не менее 10 новых подключений в месяц по компании

**Обсуждение:**

- **4.2 Прогноз достижения 10+ подключений:**

  - Отмечено улучшение качества лидов в последние две недели (приходят клиенты с трассирами и другим оборудованием)
  - Есть пилотный проект по тарифу "Стандарт"
- **4.3 Действия по стандартизации процесса продаж:** 
  - Алексей активно наполняет базу знаний, завершена работа над инструкциями по процессам поддержки
  - Проведены "глубинные интервью" с описанием процессов взаимодействия службы сопровождения с клиентами
  - Алексей "сценографировал" обучение, которое проводил Макс, сравнивая, что было рассказано разным клиентам

**Вывод:** Количество созданных сделок соответствует плану (20 в месяц), но скорость закрытия низкая (5%). Требуется ускорение процесса закрытия сделок и стандартизация обучения. Прогноз на февраль более оптимистичный.

### Маркетинг

**Выводы Евгения после маркетинговой конференции в Казахстане:**
- Конференция была слабее прошлогодней из-за большого количества рекламы
- Основные темы: казахстанский и глобальный рынки, сила бренда, глобальный маркетинг
- Полезная информация касалась дорогостоящих исследований (доля рынка, анализ конкурентов), которые больше подходят для крупных компаний

**Маркетинговые материалы:**

- Евгений предоставил файл с расчетом для клиентов, который позволяет наглядно демонстрировать на презентациях формирование абонентской платы и скидок
- Запланировано отдельное совещание по маркетинговым кампаниям, упаковочным документам и работе с возражениями
- Команде продаж поручено фиксировать все возражения клиентов во время презентаций по "Pack Light" для создания базы доводов

### 🔄 [HADI-циклы для сокращения цикла сделки](./HADI-тесты/HADI-циклы%20для%20сокращения%20цикла%20сделки.md)

- Примеры и кейсы применения

**Используйте:** При планировании оптимизации процесса продаж, сокращении цикла сделки с 84–90 дней до 40–50 дней, тестировании маркетинговых гипотез, улучшении конверсий воронки продаж (Lead→Demo, Demo→Close), систематическом улучшении процессов продаж на основе данных.

### ✅ [Валидация гипотез для HADI-циклов](./HADI-тесты/Валидация%20гипотез%20для%20HADI-циклов.md)
**Проверка предложенных гипотез на соответствие методологии HADI-циклов**

Содержит:

- Рекомендации по разделению сложных гипотез на отдельные для чистоты эксперимента
- Сводную таблицу валидации с оценками и статусами
- Общие рекомендации по приоритизации и следующие шаги

**Используйте:** При формулировке новых гипотез для тестирования, проверке соответствия гипотез методологии HADI-циклов, планировании экспериментов, улучшении формулировок гипотез перед запуском HADI-циклов.

### 📋 [Гипотезы ускорения цикла сделки (HADI)](./HADI-тесты/Гипотезы%20ускорения%20цикла%20сделки%20(HADI).md)
**Реестр гипотез для HADI-циклов в формате «новый формат»**

Содержит:
- Каталог из 27 гипотез (H01–H25, включая варианты H07a/b, H16a/b/c) для ускорения цикла сделки
- Для каждой гипотезы: формулировку H (Если… то…), действие A (один фактор), метрику и порог успеха, срок теста и сбора данных, контроль, источники данных, критерий решения (Insight), риски и варианты
- Сводную таблицу с ICE Score для приоритизации
- Группировку по темам: пилот и первый результат, демо и согласование, договор и оплата, каналы и ICP, онбординг и внедрение, коммитмент и оплата, ценообразование и стимулы
- Рекомендации по Qual (интервью/фидбек) и критерии принятия решений по результатам теста

**Используйте:** При выборе гипотез для тестирования, планировании экспериментов по сокращению цикла сделки, приоритизации по ICE, подготовке действий и сбора данных для HADI-циклов.

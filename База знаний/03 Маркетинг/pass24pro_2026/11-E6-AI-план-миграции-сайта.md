## Шаг 2. Выбранные AI-кейсы (MVP, 2 недели)

Из всего перечня работ выбраны 2 AI-кейса с наибольшим соотношением эффект/сложность:

### Кейс 1 — Автогенерация и обновление контента страниц

**Проблема:** На pass24pro.ru отсутствует или устарел контент на 5–7 ключевых страницах. Ручное написание занимает 2–4 часа на страницу.

**Решение:** Использовать ChatGPT/Claude с зафиксированным промптом и шаблоном страницы для генерации черновика контента, который затем проверяет и финализирует автор (30–45 мин вместо 3 часов).

**Сфера применения:** Страницы решений (ЖК, офис, склад), FAQ, переработка старого контента под новый тон

**Инструмент:** ChatGPT 4o или Claude Sonnet

**Промпт-шаблон:**
```
Ты — маркетолог продукта PASS24 (облачная система контроля доступа).
Напиши страницу решения для сегмента [СЕГМЕНТ].

Структура:
1. Заголовок h1 (проблема клиента)
2. Подзаголовок — что мы решаем (1 предложение)
3. Блок «Проблемы клиента» (3 пункта)
4. Блок «Как решает PASS24» (3 пункта с иконками)
5. Ключевые возможности (5–7 пунктов)
6. CTA-блок: «Оставить заявку» / «Получить консультацию»

Тон: деловой, конкретный, без воды.
Объём: 350–500 слов.
```

**Критерий готовности (DoD):**
- [ ] Промпт финализирован и задокументирован
- [ ] Сгенерированы черновики для 2 страниц (решения ЖК + офис)
- [ ] Черновики проверены автором и опубликованы или отправлены в правку
- [ ] Зафиксировано время: до AI vs после AI

**Срок:** 17.03.2026, 14:00–16:30

### Кейс 2 — Авто-проверка страниц (CTA / формы / UTM)

**Проблема:** Перед запуском тестового трафика нужно проверить 15–20 страниц на наличие корректных CTA, рабочих форм и UTM-параметров. Ручная проверка занимает 4–6 часов.

**Решение:** AI-чеклист — структурированный список критериев проверки каждой страницы + промпт для анализа HTML/текста страницы на соответствие требованиям. Итог: каждая страница получает статус OK / Fix needed с комментарием.

**Сфера применения:** Все ключевые страницы pass24pro.ru перед запуском трафика

**Инструмент:** ChatGPT 4o (анализ текста/кода) + ручная проверка форм

**Чеклист AI-проверки страницы:**
```
Проверь страницу по критериям:
1. Есть h1 с ключевым словом?
2. Есть CTA-кнопка / форма в первом экране?
3. Текст CTA конкретный («Оставить заявку», «Получить демо»), не «Узнать больше»?
4. Форма ведёт на /thank-you или передаёт событие в аналитику?
5. Нет устаревших упоминаний pass24online.ru?
6. Нет незаполненных placeholder-текстов [НАЗВАНИЕ], [ДАТА]?
7. Alt-тексты у всех изображений?
8. Мета-description заполнен (50–160 символов)?

Формат ответа: таблица «критерий — статус (OK/Fix) — комментарий»
```

**Критерий готовности (DoD):**
- [ ] Чеклист финализирован
- [ ] Прогон выполнен по всем ключевым страницам (главная + решения + тарифы + FAQ)
- [ ] Список «Fix needed» передан в разработку с приоритетами
- [ ] Повторная проверка исправленных страниц выполнена

**Срок:** 18.03.2026, 16:30–18:00

**Статус:** Запускать при необходимости, не в MVP-спринте.

## Шаг 3. Шаблоны и стандарты качества

### Стандарты контента страниц pass24pro.ru

| Параметр | Требование |
|----------|------------|
| **Тон голоса** | Деловой, конкретный, без маркетинговой воды. Фокус на проблему клиента → решение PASS24 |
| **Длина заголовка h1** | 5–12 слов, содержит ключевое слово и проблему клиента |
| **Длина страницы** | 300–700 слов (лендинг-страница), 700–1500 слов (решение/категория) |
| **CTA** | Минимум 1 CTA в первом экране + 1 в конце страницы |
| **Изображения** | Alt-текст обязателен, описывает содержание + ключевое слово |
| **Мета-description** | 120–160 символов, содержит ключевое слово + призыв |
| **Запрещено** | Фразы «лучший», «уникальный», «инновационный» без доказательств; placeholder-текст; ссылки на pass24online.ru |

### Обязательные блоки страницы решения

1. **Hero-блок** — заголовок + подзаголовок + CTA
2. **Проблемы клиента** — 3–5 болей сегмента
3. **Как решает PASS24** — конкретные функции под каждую боль
4. **Ключевые возможности** — список 5–7 пунктов
5. **Социальные доказательства** — кейсы, цифры, логотипы клиентов (если есть)
6. **CTA-блок** — форма или кнопка

### Гайд по тону для AI-промптов

```
Правильно:
✓ «Управляйте доступом в ЖК без пропускного пункта»
✓ «Система работает с любым шлагбаумом — без замены оборудования»
✓ «Среднее время внедрения — 3 дня»

Неправильно:
✗ «Инновационная облачная платформа нового поколения»
✗ «Уникальное решение для вашего бизнеса»
✗ «Мы являемся лидерами рынка»
```

## Шаг 5. Процесс работы с AI-контентом

### Схема цикла «создание → проверка → публикация»

```
1. Получить задачу (страница / тип контента)
        ↓
2. Выбрать нужный промпт из библиотеки (Шаг 3)
        ↓
3. Запустить генерацию в ChatGPT/Claude
        ↓
4. Авто-проверка чеклистом (Кейс 2)
        ↓
5. Редакторская правка (30–45 мин)
        ↓
6. Финальное утверждение (Евгений / маркетинг)
        ↓
7. Публикация на сайте
        ↓
8. QA-проверка: форма → CRM → аналитика
```

### Где хранятся версии

| Артефакт | Место хранения |
|----------|----------------|
| Промпты и шаблоны | База знаний / 03 Маркетинг / pass24pro_2026 / (этот документ) |
| Черновики страниц | Google Docs или Notion (папка «pass24pro / Контент / Черновики») |
| Финальные тексты | WordPress — в статусе «Черновик» до утверждения |
| История правок | Git / комментарии в WordPress |

### Кто что делает

| Роль | Зона ответственности |
|------|----------------------|
| Маркетолог (Евгений) | Выбор страницы, запуск AI, редакторская правка, финальное утверждение |
| Разработчик | Публикация в WordPress, настройка форм и событий аналитики |
| QA | Проверка «форма → CRM → аналитика» после публикации |

### Критерии запуска AI-генерации

Запускать AI-генерацию контента только если:
- [ ] Есть утверждённый промпт из библиотеки (Шаг 3)
- [ ] Задача согласована с маркетологом
- [ ] Страница входит в приоритетный список (P0 или P1 по карте работ)

# Серия писем — Прогрев (NEW → DEMO)

**Назначение:** Автоматическая серия из 4 писем при переходе сделки в стадию QUALIFY.
**Цель:** Подготовить клиента к демо, закрыть базовые возражения, снизить барьер входа.
**Триггер запуска:** Сделка перешла в стадию QUALIFY.
**Остановка серии:** Сделка перешла в стадию DEMO или выше.
**Персонализация:** Вводный блок подбирается автоматически по значению поля `UF_CRM_OBJECT_TYPE` в сделке.

---

## Типы объектов


| Код   | Тип объекта                 |
| ----- | --------------------------- |
| `ZHK` | Жилой комплекс (ЖК)         |
| `KP`  | Коттеджный посёлок (КП)     |
| `BC`  | Бизнес-центр (БЦ)           |
| `LOG` | Логистический центр / Склад |

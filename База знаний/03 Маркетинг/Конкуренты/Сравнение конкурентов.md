## Краткое описание

Сводное сравнение четырёх систем управления доступом: PASS24.online, A-Access (А-Доступ), Simplegate и VisitorControl. Документ построен на основе детальных анализов конкурентов из папки «Конкуренты» и описания продуктов PASS24.online. Позволяет быстро определить сильные и слабые стороны каждого решения и подобрать аргументы для продажи.

## 14. Рекомендации для продаж: аргументы против каждого конкурента

### Против A-Access

1. **Современные технологии:** PASS24 поддерживает QR, BLE, NFC, Face ID — A-Access ограничен ANPR и PIN-кодами
2. **Голосовое управление:** Интеграция с Яндекс Алисой — уникальное предложение
3. **Масштабируемость:** Без ограничений по пользователям и пропускам
4. **Гибкость авторизации:** Нет привязки к одному устройству

### Против Simplegate

1. **Встроенное распознавание номеров:** PASS24 имеет ANPR из коробки — Simplegate нет
2. **Face ID:** Биометрическая идентификация — Simplegate не поддерживает
3. **Без оборудования:** Не нужно покупать контроллеры — PASS24 работает с существующим оборудованием
4. **Больше интеграций:** Trassir, Ivideon, CVS, Автомаршал, Sigur, Bolid
5. **Без лимитов:** Нет ограничений по пользователям и точкам доступа

### Против VisitorControl

1. **Облако:** Быстрый старт без серверов — развёртывание за 1 час vs недели/месяцы

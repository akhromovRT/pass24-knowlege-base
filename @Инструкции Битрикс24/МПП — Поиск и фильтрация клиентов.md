## Краткое описание

Инструкция описывает все способы поиска клиентов в CRM: быстрый поиск, расширенные фильтры, сохранённые фильтры. Показано, как настроить персональные фильтры для ежедневной работы («Мои горячие», «С долгом» и др.), как переключаться между списком и канбаном, как искать по тегам сделок и находить компании, перенесённые из старого CRM.

---

## Пошаговая инструкция

### Шаг 1: Быстрый поиск

**Что делать:**
1. Откройте нужный раздел CRM:
   - **CRM → Компании** — для поиска компаний
   - **CRM → Контакты** — для поиска контактных лиц
   - **CRM → Сделки** — для поиска сделок
2. В верхней части страницы найдите **строку поиска**.
3. Введите запрос:
   - **Название компании** (или его часть): «Ромашка», «PASS», «ТСЖ Парк»
   - **ИНН**: «7707083893»
   - **Телефон**: «+74951234567» или «4951234567»
   - **Фамилию контакта**: «Иванов»
4. Нажмите **Enter**.

**Где:** Строка поиска в верхней части любого раздела CRM.

**Результат:** Отображается список записей, соответствующих запросу.

**Совет:** Если поиск по ИНН не находит компанию через строку поиска, используйте расширенный фильтр (Шаг 2) — ИНН хранится в реквизитах, и не все виды поиска обращаются к ним.

---

### Шаг 2: Расширенный фильтр

**Что делать:**
1. В разделе CRM (Компании, Контакты или Сделки) нажмите на иконку **фильтра** (воронка) рядом со строкой поиска.
2. Откроется панель фильтрации с доступными полями.
3. Если нужного поля нет в панели — нажмите **«+ Добавить поле»** внизу панели фильтра и выберите из списка.
4. Заполните критерии фильтрации (примеры ниже).
5. Нажмите **«Найти»** (или «Применить»).

**Полезные поля для фильтрации компаний:**

| Поле | Что фильтрует | Пример |
|------|--------------|--------|
| **Ответственный** | Менеджер, за которым закреплена компания | Выберите своё имя |
| **Балл «теплоты»** | Числовой рейтинг 0-100 | От 70 до 100 (горячие) |
| **Категория «теплоты»** | Текстовая категория | «горячий» |
| **Текущий долг** | Сумма неоплаченных счетов | Больше 0 |
| **Сумма оплат** | Сколько клиент заплатил | Больше 0 (платящие клиенты) |
| **Несколько объектов** | Флаг multi-объект | Да / Нет |

**Где:** Иконка фильтра (воронка) рядом со строкой поиска → панель фильтрации.

**Результат:** Список отфильтрован по заданным критериям.

---

### Шаг 3: Настройка сохранённых фильтров

**Что делать:** Сохранённый фильтр — это набор критериев, который можно применить одним кликом. Настройте следующие фильтры для ежедневной работы.

#### Как сохранить фильтр:
1. Откройте панель фильтрации (иконка воронки).
2. Заполните нужные критерии.
3. Нажмите **«Сохранить фильтр»** (иконка дискеты или ссылка «Сохранить»).
4. Введите название фильтра.
5. Нажмите **«Сохранить»**.

#### Рекомендуемые фильтры для компаний:

**Фильтр «Мои горячие»**
| Поле | Значение |
|------|----------|
| Ответственный | (ваше имя) |
| Балл «теплоты» | от 70 до 100 |

**Фильтр «Мои тёплые»**
| Поле | Значение |
|------|----------|
| Ответственный | (ваше имя) |
| Балл «теплоты» | от 40 до 69 |

**Фильтр «С долгом»**
| Поле | Значение |
|------|----------|
| Ответственный | (ваше имя) |
| Текущий долг | больше 0 |

#### Рекомендуемые фильтры для сделок:

**Фильтр «Мои активные сделки»**
| Поле | Значение |
|------|----------|
| Ответственный | (ваше имя) |
| Стадия | Все, кроме «Успех» и «Провал» |

**Фильтр «Без активности >30 дней»**
| Поле | Значение |
|------|----------|
| Ответственный | (ваше имя) |
| Дата последней активности | ранее чем 30 дней назад |
| Стадия | Все, кроме «Успех» и «Провал» |

**Где:** Панель фильтрации → настроить критерии → «Сохранить фильтр» → ввести название.

**Результат:** В панели фильтрации появляются ваши сохранённые фильтры. Применяйте одним кликом.

---

### Шаг 4: Фильтрация по тегам сделок

**Что делать:** Теги сделок (СТРАТЕГИЧЕСКИЙ, UPSALE, ПАРТНЁР) позволяют быстро находить определённые категории сделок.

1. Перейдите в **CRM → Сделки**.
2. Откройте панель фильтрации (иконка воронки).
3. Если поля **«Тег сделки»** нет в панели — нажмите **«+ Добавить поле»** и найдите его в списке.
4. Выберите нужный тег:
   - **СТРАТЕГИЧЕСКИЙ** — крупные клиенты, повышенный приоритет
   - **UPSALE** — действующие клиенты с договором, допродажа
   - **ПАРТНЁР** — сделки через партнёрский канал
5. Нажмите **«Найти»**.

**Совет:** Можно комбинировать тег с другими фильтрами. Например: тег = СТРАТЕГИЧЕСКИЙ + ответственный = ваше имя.

**Где:** CRM → Сделки → фильтр → поле «Тег сделки».

**Результат:** Отображаются только сделки с выбранным тегом.

---

### Шаг 5: Переключение между списком и канбаном

**Что делать:**

Битрикс24 предлагает два основных вида отображения сделок:

**Списочный вид (таблица):**
- Все сделки в виде строк таблицы.
- Удобен для массового просмотра, сортировки по столбцам, экспорта.
- Для включения: нажмите иконку **«Список»** (значок строк) в правом верхнем углу раздела Сделки.

**Канбан (доска):**
- Сделки отображаются как карточки, распределённые по столбцам-стадиям.
- Удобен для визуального контроля воронки, перетаскивания сделок между стадиями.
- Для включения: нажмите иконку **«Канбан»** (значок колонок) в правом верхнем углу.

**Переключение между воронками:**
1. В верхней части раздела Сделки найдите **вкладки воронок**: ОБЛАКО, ОБОРУДОВАНИЕ, РЕКЛАМА.
2. Кликните на нужную вкладку.
3. Отобразятся сделки только этой воронки со своими стадиями.

**Где:** CRM → Сделки → правый верхний угол (иконки переключения вида) и вкладки воронок вверху.

**Результат:** Вы можете выбрать удобный вид и нужную воронку для работы.

---

### Шаг 6: Поиск компаний, перенесённых из старого CRM

**Что делать:** Все компании, контакты и сделки, перенесённые из предыдущего Битрикс24, имеют поле **«ID из старого CRM»** (UF_CRM_OLD_B24_ID). Это позволяет найти запись, если вы помните её старый ID.

1. Перейдите в **CRM → Компании** (или Контакты).
2. Откройте панель фильтрации.
3. Нажмите **«+ Добавить поле»** и найдите **«ID из старого CRM»**.
4. Введите числовой ID из предыдущей системы.
5. Нажмите **«Найти»**.

**Совет:** Если вы не знаете точный ID, используйте обычный поиск по названию или телефону. Поле old_b24_id нужно в редких случаях, когда нужно точно сопоставить запись со старой CRM.

**Где:** Панель фильтрации → добавить поле «ID из старого CRM» → ввести значение.

**Результат:** Найдена конкретная запись, перенесённая из старой CRM-системы.

---

### Шаг 7: Использование строки поиска — полезные приёмы

**Что делать:** Несколько советов для эффективного поиска.

| Что искать | Где искать | Как вводить |
|------------|-----------|-------------|
| Компанию по названию | CRM → Компании | Часть названия: «Ромашка», «парк», «ТСЖ» |
| Компанию по ИНН | CRM → Компании → фильтр | Полный ИНН: «7707083893» |
| Компанию по телефону | CRM → Компании | Номер без пробелов: «4951234567» |
| Контакт по фамилии | CRM → Контакты | Фамилия: «Иванов» |
| Контакт по телефону | CRM → Контакты | Номер: «9161234567» |
| Сделку по названию | CRM → Сделки | Часть названия сделки |
| Глобальный поиск | Верхняя панель Битрикс24 (лупа) | Любой запрос — ищет по всем разделам CRM |

**Совет:** Глобальный поиск (лупа в верхней панели Битрикс24, не в разделе CRM) ищет по всей системе — компании, контакты, сделки, задачи, файлы. Удобно, когда не знаете точно, где искать.

**Результат:** Вы быстро находите нужную информацию в CRM.

## Типичные ошибки и их решение

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Поиск по ИНН ничего не находит | ИНН хранится в реквизитах, строка поиска может не обращаться к ним | Используйте расширенный фильтр: добавьте поле «ИНН» или ищите по названию компании |
| Не вижу нужного поля в фильтре | Поле не добавлено в панель фильтрации | Нажмите «+ Добавить поле» внизу панели фильтра и выберите нужное |
| Фильтр показывает чужие компании/сделки | Не установлен фильтр по ответственному | Добавьте в фильтр поле «Ответственный» и выберите своё имя |
| В канбане не видно сделок | Выбрана не та воронка | Переключите воронку через вкладки вверху: ОБЛАКО / ОБОРУДОВАНИЕ / РЕКЛАМА |
| Сохранённый фильтр пропал | Фильтр мог быть сброшен | Пересоздайте фильтр заново (Шаг 3) |
| Много результатов, трудно найти нужного клиента | Запрос слишком общий | Уточните запрос: добавьте больше критериев в фильтр (ответственный, балл теплоты, наличие долга) |
| Не могу найти перенесённую компанию | Не знаете точное название в новой CRM | Попробуйте фильтр по полю «ID из старого CRM», если помните старый ID. Или ищите по ИНН/телефону |

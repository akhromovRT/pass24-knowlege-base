## Краткое описание

Данный документ определяет правила и стандарты создания инструкций для конечных пользователей нового CRM Битрикс24 (pass24pro.bitrix24.ru). Инструкции создаются по итогам каждого завершённого этапа миграции или настройки функционала и публикуются в корпоративную базу знаний PASS24.online.

---

## Когда создавать инструкцию

Инструкция создаётся **по факту завершения каждого этапа миграции или настройки**, а именно:

1. **Перенос клиентской базы** — инструкция по работе с карточками компаний и контактов
2. **Настройка воронок и стадий** — инструкция по ведению сделок в новых воронках
3. **Настройка пользовательских полей** — инструкция по заполнению и использованию кастомных полей
4. **Настройка рабочих групп** — инструкция по работе с группами клиентов и партнёров
5. **Настройка автоматизации** — инструкция по роботам, триггерам, бизнес-процессам
6. **Настройка прав доступа** — инструкция по ролям и ограничениям
7. **Настройка телефонии и коммуникаций** — инструкция по звонкам, чатам, email
8. **Любое другое изменение**, затрагивающее работу пользователей

### Принципы написания

1. **Язык пользователя, а не разработчика.** Пишите «Нажмите кнопку "Сохранить"», а не «Вызовите метод crm.deal.update». Пользователь не знает API.
2. **Один документ — одна задача.** «Как создать сделку в воронке ОБЛАКО» — отдельная инструкция. «Как работать с CRM» — слишком широко.
3. **Пошагово с указанием места.** Каждый шаг содержит: что сделать, где в интерфейсе, что должно получиться.
4. **Скриншоты и визуал.** Скриншоты интерфейса Битрикс24 с пометками (стрелки, выделения) размещаются в `6_Attachments/` (Obsidian) или в папке изображений базы знаний.
5. **Предупреждения явно.** Если действие необратимо или критично — выделять блоком `**⚠️ Внимание:**`.
6. **Привязка к роли.** Каждая инструкция помечена ролью (менеджер по продажам, руководитель ОП, администратор и т.д.).

### Именование файлов

Формат: `[Роль] — [Что делать] [контекст].md`

Примеры:
- `МПП — Работа с карточками клиентов.md`
- `МПП — Ведение сделок в воронке ОБЛАКО.md`
- `РОП — Контроль воронки продаж.md`
- `Администратор — Управление правами доступа.md`

Сокращения ролей:
- **МПП** — менеджер по продажам
- **РОП** — руководитель отдела продаж
- **МС** — менеджер по сопровождению
- **Админ** — администратор системы

## Процесс создания инструкции

### Шаг 1: Завершить этап миграции/настройки

Убедиться, что функционал работает корректно в новом Битрикс24. Провести финальную проверку.

### Шаг 2: Определить затронутые роли

Для каждого этапа определить, какие роли пользователей затронуты и какие действия им нужно будет выполнять.

### Шаг 3: Создать черновик инструкции

Использовать шаблон из корпоративной базы знаний. Описать процесс с точки зрения конечного пользователя. Сохранить в папку `переезд Б24/@Инструкции Битрикс24/`.

### Шаг 4: Добавить визуальные материалы

Сделать скриншоты реального интерфейса нового Битрикс24 с пометками.

### Шаг 5: Проверить и согласовать

Проверить инструкцию на соответствие стандартам. При необходимости — согласовать с руководителем отдела.

### Шаг 6: Опубликовать в базу знаний

Готовую инструкцию перенести в репозиторий корпоративной базы знаний (`pass24-knowlege-base`) через Pull Request по установленному процессу.

### Шаг 7: Обновить структуру инструкций

Обновить файл `Структура инструкций по ролям.md` — отметить инструкцию как готовую.
